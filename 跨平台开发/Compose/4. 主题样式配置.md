## MaterialTheme

Material 3 的主题由三个子系统构成，`MaterialTheme` 是它们的统一入口：

| 子系统 | 参数 | 作用 |
|---|---|---|
| 配色方案 | `colorScheme: ColorScheme` | 定义所有颜色角色（primary / surface / error 等） |
| 排版 | `typography: Typography` | 定义 15 个文本样式 |
| 形状 | `shapes: Shapes` | 定义 5 档圆角 |

### 标准写法

```kotlin
@Composable
fun AppTheme(
    darkTheme: Boolean = isSystemInDarkTheme(),
    dynamicColor: Boolean = true,
    content: @Composable () -> Unit
) {
    val colorScheme = when {
        dynamicColor && Build.VERSION.SDK_INT >= Build.VERSION_CODES.S -> {
            val context = LocalContext.current
            if (darkTheme) dynamicDarkColorScheme(context) else dynamicLightColorScheme(context)
        }
        darkTheme -> DarkColorScheme
        else -> LightColorScheme
    }

    MaterialTheme(
        colorScheme = colorScheme,
        typography = AppTypography,
        shapes = AppShapes,
        content = content
    )
}
```

要点：

- `darkTheme` 默认取 `isSystemInDarkTheme()`，跟随系统深色模式；也可外部传入以便应用内手动切换。
- `dynamicColor` 是动态取色开关，仅 Android 12（API 31）及以上可用，低于此版本自动回退到自定义方案。
- 三个参数均可省略，省略时继承外层主题、最终回退到 M3 默认值。因此可以在子树内再包一层 `MaterialTheme`，只覆盖需要改的部分。

### 读取主题值

所有主题值只能在 `@Composable` 上下文中读取：

```kotlin
val primary = MaterialTheme.colorScheme.primary
val titleStyle = MaterialTheme.typography.titleLarge
val cardShape = MaterialTheme.shapes.medium
```

### 局部覆盖

```kotlin
MaterialTheme(
    typography = MaterialTheme.typography.copy(
        bodyLarge = MaterialTheme.typography.bodyLarge.copy(fontWeight = FontWeight.Bold)
    )
) {
    // 该子树内 bodyLarge 为粗体，其余样式不变
}
```

`ColorScheme`、`Typography`、`Shapes` 均为 data class，用 `copy()` 只改目标字段，其余沿用。

### 状态栏配色（可选）

```kotlin
val view = LocalView.current
if (!view.isInEditMode) {
    SideEffect {
        val window = (view.context as Activity).window
        window.statusBarColor = colorScheme.primary.toArgb()
        WindowCompat.getInsetsController(window, view).isAppearanceLightStatusBars = !darkTheme
    }
}
```

`isInEditMode` 判断用于跳过预览环境，避免预览时强转 `Activity` 失败。

> 注意：`MaterialTheme` 属于 Material 3 的 `androidx.compose.material3` 包，与 Material 2 的同名 API 不兼容，不可混用。

## Color

### ColorScheme 的构造

```kotlin
val LightColorScheme = lightColorScheme(
    primary = Color(0xFF6750A4),
    onPrimary = Color(0xFFFFFFFF),
    primaryContainer = Color(0xFFEADDFF),
    onPrimaryContainer = Color(0xFF21005D),
    secondary = Color(0xFF625B71),
    onSecondary = Color(0xFFFFFFFF),
    tertiary = Color(0xFF7D5260),
    background = Color(0xFFFFFBFE),
    onBackground = Color(0xFF1C1B1F),
    surface = Color(0xFFFFFBFE),
    onSurface = Color(0xFF1C1B1F),
    error = Color(0xFFB3261E),
    onError = Color(0xFFFFFFFF),
    outline = Color(0xFF79747E)
)

val DarkColorScheme = darkColorScheme(
    primary = Color(0xFFD0BCFF),
    onPrimary = Color(0xFF381E72),
    // 其余角色同理，深色主题应使用更浅的主色与更深的容器色
)
```

### 颜色角色分类

| 分类 | 角色 | 说明 |
|---|---|---|
| 主色 | `primary` / `onPrimary` / `primaryContainer` / `onPrimaryContainer` | 品牌主色，用于关键操作、选中态 |
| 次色 | `secondary` / `onSecondary` / `secondaryContainer` / `onSecondaryContainer` | 辅助色，用于次要元素 |
| 第三色 | `tertiary` / `onTertiary` / `tertiaryContainer` / `onTertiaryContainer` | 点缀色，用于对比强调 |
| 背景 | `background` / `onBackground` | 页面底色与其上文字 |
| 表面 | `surface` / `onSurface` / `surfaceVariant` / `onSurfaceVariant` | 卡片、面板等承载内容的表面 |
| 错误 | `error` / `onError` / `errorContainer` / `onErrorContainer` | 错误态 |
| 描边 | `outline` / `outlineVariant` / `scrim` | 边框、分割线、遮罩 |

### on 前缀的含义

`onXxx` 是「Xxx 之上的前景色」，成对使用以保证对比度：

- `primary` 作背景时，其上文字用 `onPrimary`；
- `surface` 作背景时，其上文字用 `onSurface`。

反用（`primary` 当文字、`onPrimary` 当背景）虽语法合法，但对比度关系颠倒，深色模式下极易出现「浅底浅字」的不可读问题。

### 动态取色

Android 12（API 31）起，可从系统壁纸提取配色：

```kotlin
val context = LocalContext.current
val colorScheme = if (darkTheme) {
    dynamicDarkColorScheme(context)
} else {
    dynamicLightColorScheme(context)
}
```

调用前需判断 `Build.VERSION.SDK_INT >= Build.VERSION_CODES.S`，否则低版本运行时会崩溃。动态取色只覆盖默认配色，不影响组件结构。

### 自定义配色方案

手写 20 多个颜色角色既繁琐又易错，官方推荐用 **Material Theme Builder** 工具：输入品牌源色，自动展开为完整色调板，并可直接导出 Compose 的 `Color.kt` 与 `Theme.kt` 代码。

### 常见误区

1. **硬编码颜色**：`Color(0xFF6750A4)` 写死在组件里，深色模式不会自动适配，必须改为 `MaterialTheme.colorScheme.primary`。
2. **on 前缀用反**：`onPrimary` 是前景色，不是「primary 的替代品」。
3. **误以为 M3 有 `isLight` 参数**：M2 的 `Colors.isLight` 在 M3 的 `ColorScheme` 中已移除，需要判断深浅色时应在主题层用 `LocalIsDarkTheme` 之类的 CompositionLocal 自行提供。

## Typography

### 15 个文本样式

M3 的排版系统按「5 类 × 3 号」组织：

| 分类 | Large | Medium | Small | 典型用途 |
|---|---|---|---|---|
| display | `displayLarge` | `displayMedium` | `displaySmall` | 超大标题、关键数字 |
| headline | `headlineLarge` | `headlineMedium` | `headlineSmall` | 页面主标题 |
| title | `titleLarge` | `titleMedium` | `titleSmall` | 区块标题、卡片标题 |
| body | `bodyLarge` | `bodyMedium` | `bodySmall` | 正文段落 |
| label | `labelLarge` | `labelMedium` | `labelSmall` | 按钮文字、标签、辅助说明 |

字号从 `displayLarge`（最大）到 `labelSmall`（最小）递减；同分类内 Large > Medium > Small。

### TextStyle 的组成

每个样式是一个 `TextStyle`，由五个要素决定：

```kotlin
TextStyle(
    fontFamily = FontFamily.Default,
    fontWeight = FontWeight.Normal,
    fontSize = 16.sp,
    lineHeight = 24.sp,
    letterSpacing = 0.5.sp
)
```

- `fontSize`：字号（sp）
- `lineHeight`：行高（sp），多行文本的行间距由它控制
- `letterSpacing`：字间距（sp，不是 em）
- `fontWeight`：字重（Normal / Medium / SemiBold / Bold 等）
- `fontFamily`：字体族

### 自定义 Typography

只覆盖需要改的样式，其余省略即沿用 M3 默认值：

```kotlin
val AppTypography = Typography(
    headlineSmall = TextStyle(
        fontWeight = FontWeight.SemiBold,
        fontSize = 24.sp,
        lineHeight = 32.sp,
        letterSpacing = 0.sp
    ),
    titleLarge = TextStyle(
        fontWeight = FontWeight.Normal,
        fontSize = 22.sp,
        lineHeight = 28.sp,
        letterSpacing = 0.sp
    ),
    bodyLarge = TextStyle(
        fontWeight = FontWeight.Normal,
        fontSize = 16.sp,
        lineHeight = 24.sp,
        letterSpacing = 0.5.sp
    ),
    labelLarge = TextStyle(
        fontWeight = FontWeight.Medium,
        fontSize = 14.sp,
        lineHeight = 20.sp,
        letterSpacing = 0.1.sp
    )
)
```

### 自定义字体

```kotlin
val AppFontFamily = FontFamily(
    Font(R.font.inter_regular, FontWeight.Normal),
    Font(R.font.inter_medium, FontWeight.Medium),
    Font(R.font.inter_bold, FontWeight.Bold)
)

val AppTypography = Typography(
    bodyLarge = TextStyle(fontFamily = AppFontFamily, fontSize = 16.sp)
)
```

字体文件放在 `res/font/` 目录，通过 `R.font.xxx` 引用。同一 `FontFamily` 内按 `FontWeight` 注册多个字体文件，Compose 会按字重自动选择。

### 常见误区

1. **组件内硬编码 `fontSize`**：应统一走 `MaterialTheme.typography.xxx`，否则改主题时遗漏。
2. **`letterSpacing` 当成 em**：Compose 中单位是 sp，与 CSS 的 em 不同。
3. **试图覆盖全部 15 个样式**：只改实际用到的，其余交给默认值，维护成本更低。

## Shape

### 5 档圆角

`Shapes` 提供五个尺寸档位，M3 默认值如下：

| 档位 | 默认圆角 | 典型用途 |
|---|---|---|
| `extraSmall` | 4.dp | 小型标签、Chip |
| `small` | 8.dp | 输入框、小卡片 |
| `medium` | 12.dp | 常规卡片 |
| `large` | 16.dp | 大卡片、面板 |
| `extraLarge` | 28.dp | 弹窗、底部抽屉 |

### 自定义 Shapes

```kotlin
val AppShapes = Shapes(
    extraSmall = RoundedCornerShape(4.dp),
    small = RoundedCornerShape(8.dp),
    medium = RoundedCornerShape(12.dp),
    large = RoundedCornerShape(16.dp),
    extraLarge = RoundedCornerShape(28.dp)
)
```

支持两种切角方式：

- `RoundedCornerShape(dp)`：圆角
- `CutCornerShape(dp)`：斜切角

也可逐角指定：`RoundedCornerShape(topStart = 12.dp, bottomEnd = 12.dp)`。

### 组件中的使用

M3 组件内部按语义选取对应档位，例如卡片取 `medium`、弹窗取 `extraLarge`。自定义组件应同样通过主题取值，而非硬编码：

```kotlin
Surface(
    shape = MaterialTheme.shapes.medium,
    color = MaterialTheme.colorScheme.surface
) {
    // 内容
}
```

若某组件暴露了 `shape` 参数，显式传入 `MaterialTheme.shapes.xxx` 即可覆盖其默认值。

### 常见误区

1. **硬编码 `RoundedCornerShape(12.dp)`**：改主题时无法统一调整，应取 `MaterialTheme.shapes.medium`。
2. **以为所有组件都能改圆角**：部分组件（如 `Button`）的圆角由内部样式固定，需通过 `shape` 参数或自定义实现覆盖。
3. **混用 M2 与 M3 的 Shapes**：`androidx.compose.material.Shapes` 与 `androidx.compose.material3.Shapes` 是两个类，不可互传。
