## SQL语句种类

SQL语句按功能可划分为五类：DDL（数据定义语言）、DML（数据操纵语言）、DQL（数据查询语言）、DCL（数据控制语言）以及TCL（事务控制语言）：

+ DDL：包含CREATE、DROP以及ALTER

  CREATE: 创建数据库和表等对象；

  DROP: 删除数据库和表等对象；

  ALTER: 修改数据库和表等对象的结构。

+ DML：包含INSERT、UPDATE以及DELETE

  INSERT: 向表中插入数据；

  UPDATE: 更新表中数据；

  DELETE: 删除表中数据。

+ DQL：包含SELECT

  SELECT: 查询表中数据。

+ DCL：包含GRANT以及REVOKE

  GRANT: 赋予用户操作权限；

  REVOKE: 取消用户的操作权限。

+ TCL：包含COMMIT、ROLLBACK以及SAVEPOINT

  COMMIT: 确认对数据库中的数据进行的变更；

  ROLLBACK: 取消对数据库中的数据进行的变更；

  SAVEPOINT: 设置事务内的回滚点。

> 说明：不同资料对语句分类略有差异，例如部分资料将 SELECT 归入 DML，或将 COMMIT/ROLLBACK 归入 DCL；本文采用 SQL 标准主流的五类划分。

## 基本书写规则

1. SQL语句以分号结尾；
2. 关键字不区分大小写；
3. 字符串和日期需要用单引号括起来标识，数字不用；
4. 单词之间用空格或换行分隔。

## 数据类型

MySQL 支持的数据类型主要分为数值类型、字符串类型、日期时间类型以及其他类型几大类。

### 数值类型

整数类型（精确值）：

| 类型 | 占用字节 | 有符号范围 | 无符号范围 |
| --- | --- | --- | --- |
| TINYINT | 1 | -128 ~ 127 | 0 ~ 255 |
| SMALLINT | 2 | -32768 ~ 32767 | 0 ~ 65535 |
| MEDIUMINT | 3 | -8388608 ~ 8388607 | 0 ~ 16777215 |
| INT / INTEGER | 4 | -2147483648 ~ 2147483647 | 0 ~ 4294967295 |
| BIGINT | 8 | -9223372036854775808 ~ 9223372036854775807 | 0 ~ 18446744073709551615 |

整数类型可以通过 UNSIGNED 关键字声明为无符号（只存非负值），默认是有符号。

浮点类型（近似值）：

+ FLOAT：单精度浮点数，占用 4 字节；
+ DOUBLE：双精度浮点数，占用 8 字节。

定点类型（精确值）：

+ DECIMAL(M,D)：精确小数，M 为总位数（最大 65），D 为小数位数（最大 30），适合存储金额等需要精确表示的数据。

位值类型：

+ BIT(M)：存储位值，M 为位数。

### 字符串类型

+ CHAR(M)：定长字符串，长度固定，最多 255 字符；
+ VARCHAR(M)：变长字符串，最多 65535 字节（实际还受单行最大字节数及字符集限制）；
+ TEXT 系列：用于存储较长文本，按容量从小到大依次为 TINYTEXT、TEXT、MEDIUMTEXT、LONGTEXT；
+ BLOB 系列：用于存储二进制数据，按容量从小到大依次为 TINYBLOB、BLOB、MEDIUMBLOB、LONGBLOB；
+ ENUM：枚举类型，取值必须是创建表时指定值列表中的某一个；
+ SET：集合类型，取值是创建表时指定值列表中 0 个或多个值的组合。

### 日期时间类型

+ DATE：日期，格式 YYYY-MM-DD，范围 1000-01-01 ~ 9999-12-31；
+ TIME：时间，格式 HH:MM:SS，范围为 -838:59:59 ~ 838:59:59；
+ DATETIME：日期时间，格式 YYYY-MM-DD HH:MM:SS，范围 1000-01-01 00:00:00 ~ 9999-12-31 23:59:59；
+ TIMESTAMP：时间戳，范围 1970-01-01 00:00:01 UTC ~ 2038-01-19 03:14:07 UTC，存储时会受时区影响；
+ YEAR：年份，范围 1901 ~ 2155。

### 其他类型

+ JSON：用于存储 JSON 格式的数据（MySQL 5.7.8 起支持）；
+ 空间类型：如 GEOMETRY、POINT、LINESTRING 等，用于存储地理空间数据。

## 算术运算符

基本的算术运算符包括+（加法）、-（减法）、*（乘法）和/（除法），在这一基础之上，还有比较运算符， 包括=（等于）、>（大于）、<（小于）、<=（小于等于）、>=（大于等于）以及<>（不等于）。在 MySQL 中， 可以使用不带 FROM 的 SELECT 语句来显示运算结果；比较运算需要使用 WHERE 子句。

```sql
--算术运算：
SELECT <expression> [AS <result>]; --AS是可选的

--比较运算：
SELECT <name_cols>
FROM <name_table>
WHERE <expression>;
```

对 NULL 进行算术运算，其结果仍然是 NULL。对字符串和数字运用比较运算符时，要注意它们之间的区别。

## 逻辑运算符

常用的逻辑运算符包括 AND（与）、OR（或）和 NOT（非），在判断 NULL 时，需要使用 IS NULL 或 IS NOT NULL。 逻辑运算符通常用于 WHERE 子句中。

```sql
SELECT <name_col>
FROM <name_table>
WHERE [NOT <cond>]
        [<cond 1> AND <cond 2>]
        [<cond 1> OR <cond 2>]
        [<cond> IS NULL]
        [<cond> IS NOT NULL];
```

在 MySQL 中，由于 NULL 的存在，逻辑运算真值表不再是简单的 TRUE（真）和 FALSE（假），而是又多了一个"不确定（UNKNOWN）"。

## CASE表达式

CASE 表达式相当于其他编程语言当中的条件（分支）语句，分为简单 CASE 表达式和搜索 CASE 表达式。

### 简单 CASE 表达式

简单 CASE 表达式的一般用法为：

```sql
CASE <expression>
    WHEN <expression 1> THEN <expression>
    WHEN <expression 2> THEN <expression>
    WHEN <expression 3> THEN <expression>
    ···
    ELSE <expression>
END
```

简单 CASE 表达式的执行逻辑是：依次将 CASE 后的表达式与各个 WHEN 后的值进行等值比较，返回第一个相等项对应的 THEN 结果；若均不相等则返回 ELSE 结果。

将上面的语句与其他语言中的 switch-case 进行对比，就可以发现有高度相似之处：

```c
switch(<case>) {
    case <cond 1>: //TODO
    case <cond 2>: //TODO
    ···
    default: //TODO
}
```

### 搜索 CASE 表达式

搜索 CASE 表达式的一般用法为：

```sql
CASE WHEN <expression 1> THEN <expression>
    WHEN <expression 2> THEN <expression>
    WHEN <expression 3> THEN <expression>
    ···
    ELSE <expression>
END
```

搜索 CASE 表达式的执行逻辑是：从上到下依次判断各 WHEN 后的条件表达式是否为真，返回第一个为真的 WHEN 对应的 THEN 结果；若均不成立则返回 ELSE 结果。

将上面的语句与其他语言的 if-else 进行对比，同样能发现许多相似之处：

```c
if (cond 1) {
    //TODO
} else if (cond 2) {
    //TODO
} ··· else {
    //TODO
}
```

注意：CASE 表达式中的 ELSE 子句是可选的，若省略 ELSE 且所有 WHEN 均不匹配，则返回 NULL。
