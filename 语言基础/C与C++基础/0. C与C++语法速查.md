## 版本基线

当前 NDK LTS 为 r30（`30.0.16248370`，2026-09-08 发布），工具链为 Clang 21.0.0，STL 为 libc++。官方文档对 C 的承诺是标准 C11 库头文件可用，对 C++ 的承诺是 C++17 支持可用；CMake 的默认标准仍取 Clang 默认值（C++14），使用 C++17 及以上必须显式设置。

| 语言 | 工程基线 | 可用上限 | 说明 |
| --- | --- | --- | --- |
| C | C11 | C17 全部、C23 部分 | bionic 保证 C11 头文件；C23 的新增库函数不保证在所有 API 级别存在 |
| C++ | C++17 | C++20 可用、C++23 部分 | 语言特性由 Clang 21 支持，库特性覆盖以所配 libc++ 为准 |

```cmake
set(CMAKE_C_STANDARD 11)
set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)
```

```bash
clang   -std=c11   -c foo.c   -o foo.o
clang++ -std=c++17 -c foo.cpp -o foo.o
```

## 基本类型与宽度

| 类型 | 宽度（LP64 / ILP32） | 说明 |
| --- | --- | --- |
| `char` | 1 / 1 | 是否有符号由实现决定，Android 上为有符号 |
| `short` | 2 / 2 | — |
| `int` | 4 / 4 | — |
| `long` | 8 / 4 | ABI 差异点，`arm64-v8a` 为 8，`armeabi-v7a` 为 4 |
| `long long` | 8 / 8 | — |
| 指针 | 8 / 4 | — |
| `size_t` | 8 / 4 | 无符号，`sizeof` 的结果类型 |
| `ptrdiff_t` | 8 / 4 | 有符号，指针相减的结果类型 |

定宽类型来自 `<stdint.h>` / `<cstdint>`：`int8_t`…`int64_t`、`uint8_t`…`uint64_t`、`intptr_t`、`uintptr_t`。跨 JNI 边界一律使用定宽类型，`jlong` 对应 `int64_t`。

```c
#include <stdint.h>
int64_t deadline = 0;      /* 不要用 long 接收 jlong */
uint32_t hash = 2166136261u;
```

`bool`：C 需要 `<stdbool.h>`（C23 起为关键字），C++ 为内置类型。`NULL` 在 C 中是 `void *` 或 0，C++11 起用 `nullptr`。

## 声明与初始化

```c
int a = 1;                 /* 拷贝初始化 */
int b = {2};               /* C99 起可用花括号 */
int arr[3] = {1, 2, 3};
int zeros[8] = {0};        /* 其余元素补 0 */
struct Point p = {.x = 1, .y = 2};      /* C99 指定初始化 */
struct Point q = (struct Point){1, 2};  /* C99 复合字面量，C++ 不支持 */
```

```cpp
int a = 1;
int b{2};                  /* 列表初始化，禁止窄化转换 */
int arr[]{1, 2, 3};        /* 长度由初始化列表推导 */
auto p = std::make_pair(1, 2.0);
constexpr int kMax = 64;   /* 编译期常量 */
Point p{.x = 1, .y = 2};   /* C++20 指定初始化，必须按声明顺序 */
```

`auto` 在两门语言中含义不同：C 是存储类说明符（C23 起也可做类型推导），C++11 起是类型推导占位符。

## 指针与数组声明

| 声明 | 含义 |
| --- | --- |
| `int *p` | 指向 int 的指针 |
| `const int *p` | 指向 const int 的指针，目标值不可改 |
| `int * const p` | 常量指针，指向不可改 |
| `int *p[4]` | 4 个元素的数组，元素为 `int *` |
| `int (*p)[4]` | 指向 `int[4]` 的指针 |
| `int (*p)(int)` | 指向函数的指针 |
| `int (&r)[4]` | 数组的引用（C++） |
| `int *f(int)` | 返回 `int *` 的函数 |
| `int (*f(int))(int)` | 返回函数指针的函数 |

C++ 引用的三条约束：必须初始化、不可重新绑定、没有空引用。函数参数用 `const T &` 表示只读借用，用 `T &&` 表示可移动的右值。

```cpp
void read(const std::string &s);   // 只读借用
void take(std::string &&s);        // 接管右值
```

## 运算符

| 类别 | 运算符 |
| --- | --- |
| 算术 | `+ - * / %`，`++ --` |
| 关系 | `== != < <= > >=`，`<=>`（C++20） |
| 逻辑 | `&& || !` |
| 位 | `& | ^ ~ << >>` |
| 赋值 | `= += -= *= /= %= &= |= ^= <<= >>=` |
| 其他 | `?:`、`,`、`sizeof`、`alignof`、`typeid`、`static_cast` 等 |

优先级只需记住四个易错点：

```c
*p++          /* 等价于 *(p++)，不是 (*p)++ */
a & b == c    /* 等价于 a & (b == c)，== 优先级高于 & */
a << 1 + 2    /* 等价于 a << 3，+ 优先级高于 << */
!a & b        /* 等价于 (!a) & b */
```

位运算与比较混用时一律加括号，这是 native 代码中最常见的一类静默错误。

## 控制流

```c
if (cond) { } else if (cond2) { } else { }

switch (code) {
case 1:
    /* 贯穿到 case 2 */
case 2:
    break;
default:
    break;
}

for (int i = 0; i < n; ++i) { }
while (cond) { }
do { } while (cond);
```

```cpp
if (auto it = m.find(key); it != m.end()) { }   // C++17 带初始化语句

for (const auto &item : items) { }              // C++11 范围 for

switch (auto v = next(); v) {                    // C++17
case 0: break;
default: break;
}

for (int i = 0; i < n; ++i) { }
```

`switch` 的 `case` 标签必须是整型常量表达式。C++ 中在 `case` 内定义变量需要额外花括号限定作用域。

```cpp
switch (x) {
case 1: {
    int tmp = compute();
    use(tmp);
    break;
}
default:
    break;
}
```

## 函数

```c
int add(int a, int b);                 /* 声明 */
int add(int a, int b) { return a + b; }

void swap(int *a, int *b);             /* 输出参数用指针 */
int *find(const char *key);            /* 返回指针，所有权需约定 */

static inline int square(int v) { return v * v; }
```

```cpp
int add(int a, int b = 0);             // 默认参数，只能出现在声明中一次
int add(int a, int b) { return a + b; }

double area(double r);                  // 重载
double area(double w, double h);

constexpr int square(int v) { return v * v; }   // C++11
consteval int cube(int v) { return v * v * v; } // C++20，必须编译期求值

[[nodiscard]] int parse(const char *s);          // C++17，忽略返回值产生警告
```

C 不支持重载与默认参数。需要“同名不同参”时只能改函数名，或使用可变参数与结构体参数。

可变参数：C 用 `<stdarg.h>` 的 `va_list` / `va_start` / `va_arg` / `va_end`；C++ 优先使用模板参数包或 `std::initializer_list`。

## 结构体、枚举与联合

```c
struct Point { int x; int y; };
typedef struct Point Point;            /* C 中省略 typedef 时需写 struct Point */

enum Color { RED, GREEN = 5, BLUE };   /* 底层类型由实现决定 */

union Value { int i; float f; };       /* 同一存储的多种解释，写入一个成员后读另一个是未定义行为 */

struct Flags {
    unsigned ready : 1;                /* 位域，布局由 ABI 决定 */
    unsigned mode  : 3;
};
```

```cpp
struct Point { int x = 0; int y = 0; };   // 成员默认初始化

enum class Color : uint8_t { Red, Green = 5, Blue };  // 强类型枚举，不隐式转换

union Value { int i; float f; };           // C++ 中可含非平凡成员，但需自行管理生命周期
```

`enum class` 必须写作用域限定（`Color::Red`），不与整数隐式互转，这是 C++ 侧应优先使用的形式。

结构体布局受对齐影响：

```c
struct A { char c; int i; };      /* sizeof 通常为 8：1 字节 + 3 填充 + 4 */
struct B { int i; char c; };      /* sizeof 通常为 8：4 + 1 + 3 尾部填充 */
```

跨进程或跨语言传递结构体时，布局必须显式约定，不能依赖编译器默认对齐。`offsetof`（`<stddef.h>`）用于确认成员偏移。

## 类

```cpp
class Buffer {
public:
    explicit Buffer(size_t n) : data_(new char[n]), size_(n) {}
    ~Buffer() { delete[] data_; }

    Buffer(const Buffer &) = delete;
    Buffer &operator=(const Buffer &) = delete;

    Buffer(Buffer &&other) noexcept
        : data_(other.data_), size_(other.size_) {
        other.data_ = nullptr;
        other.size_ = 0;
    }

    size_t size() const { return size_; }

protected:
    char *data_;

private:
    size_t size_;
};

class Growable : public Buffer {
public:
    using Buffer::Buffer;
    ~Growable() override = default;
    void resize(size_t n);
};
```

| 语法 | 含义 |
| --- | --- |
| `explicit` | 禁止单参数构造的隐式转换 |
| `= default` | 要求编译器生成默认实现 |
| `= delete` | 禁用该函数 |
| `override` | 声明重写，签名不匹配时报错 |
| `final` | 禁止继续重写或继承 |
| `virtual ... = 0` | 纯虚函数，类成为抽象类 |
| `noexcept` | 声明不抛异常，移动构造应标注 |
| `friend` | 授权访问私有成员 |
| `static` 成员 | 属于类而非对象 |

基类析构必须为 `virtual`，否则通过基类指针删除派生对象是未定义行为。构造与析构中调用虚函数不会派发到派生类。

## 内存与所有权

```c
int *p = (int *)malloc(10 * sizeof(int));
if (p != NULL) {
    free(p);
}
```

```cpp
auto p = std::make_unique<int[]>(10);          // 独占数组
auto q = std::make_unique<Buffer>(1024);       // 独占对象
auto shared = std::make_shared<Buffer>(1024);  // 共享对象
std::weak_ptr<Buffer> weak = shared;           // 观察，不增加计数
```

| 操作 | 语义 |
| --- | --- |
| `new T` / `delete` | 构造/析构单个对象 |
| `new T[n]` / `delete[]` | 构造/析构数组，必须配对 |
| `malloc` / `free` | 只分配原始内存，不调用构造/析构 |
| `make_unique` / `make_shared` | 异常安全，后者单次分配 |
| `get()` | 取裸指针，不转移所有权 |
| `release()` | 放弃所有权，返回裸指针 |
| `reset()` | 释放当前对象并接管新对象 |

`shared_ptr` 的引用计数操作是原子的，但同一 `shared_ptr` 实例的并发读写需要额外同步；被指向对象的并发访问与引用计数无关。

## 标准库常用

| 用途 | 头文件 | 常用形式 |
| --- | --- | --- |
| 字符串 | `<string>` | `std::string`、`substr`、`find`、`c_str` |
| 动态数组 | `<vector>` | `push_back`、`reserve`、`erase`、`size` |
| 定长数组 | `<array>` | `std::array<int, 4>` |
| 有序映射 | `<map>` | `find`、`insert`、`try_emplace` |
| 哈希映射 | `<unordered_map>` | `find`、`insert`、`reserve` |
| 只读字符视图 | `<string_view>`（C++17） | 非拥有，生命周期由源对象决定 |
| 可选值 | `<optional>`（C++17） | `has_value`、`value_or` |
| 多选一 | `<variant>`（C++17） | `std::get`、`std::visit` |
| 算法 | `<algorithm>` | `sort`、`find`、`transform`、`any_of` |
| 数值 | `<numeric>` | `accumulate`、`iota` |

```cpp
std::vector<int> v{3, 1, 2};
std::sort(v.begin(), v.end());
auto it = std::find(v.begin(), v.end(), 2);
if (it != v.end()) {
    ptrdiff_t index = it - v.begin();
}
```

`vector` 扩容后所有迭代器与元素指针失效；`map` 只在删除元素时失效；`unordered_map` 在 rehash 时迭代器失效但元素指针保持有效。

## 模板

```cpp
template <typename T>
T max_of(T a, T b) { return a > b ? a : b; }

template <typename T, size_t N>
constexpr size_t count_of(T (&)[N]) { return N; }

template <typename... Args>
void log_all(const Args &...args);           // C++11 参数包

template <std::integral T>                   // C++20 概念约束
T twice(T v) { return v * 2; }
```

模板定义必须对使用点可见，因此实现放在头文件。C++20 的 `requires` 与概念把约束写进签名，报错信息比 SFINAE 清晰：

```cpp
template <typename T>
    requires std::is_integral_v<T>
T twice(T v) { return v * 2; }
```

## Lambda

```cpp
auto add = [](int a, int b) { return a + b; };
auto by_ref = [&total](int v) { total += v; };
auto init = [n = 0]() mutable { return ++n; };   // C++14 初始化捕获
auto generic = [](auto a, auto b) { return a + b; };  // C++14 泛型 lambda
```

捕获列表决定生命周期：`[&]` 捕获引用，闭包存活超过被捕获对象时失效；`[=]` 捕获值，对象需可拷贝。默认捕获可与显式捕获组合（如 `[=, &x]`），但显式捕获的变量不能与默认方式重复，`[=, x]` 非法。

## 异常

```cpp
try {
    throw std::runtime_error("failed");
} catch (const std::runtime_error &e) {
    log(e.what());
} catch (const std::exception &e) {
    log(e.what());
} catch (...) {
    throw;
}
```

| 语法 | 含义 |
| --- | --- |
| `throw expr;` | 抛出异常 |
| `catch (const T &e)` | 按 const 引用捕获，避免切片与拷贝 |
| `catch (...)` | 捕获所有类型 |
| `throw;` | 重新抛出当前异常 |
| `noexcept` | 声明不抛，违反时调用 `std::terminate` |
| `noexcept(expr)` | 条件声明 |

析构函数默认 `noexcept`。JNI 边界上不应让 C++ 异常越过 `extern "C"` 函数，未捕获异常会触发 `std::terminate`，在 Android 上表现为 `SIGABRT`。

## 预处理与头文件

```c
#ifndef EXAMPLE_H
#define EXAMPLE_H

#include <stddef.h>

#define MAX(a, b) ((a) > (b) ? (a) : (b))

#if defined(__aarch64__)
/* arm64 分支 */
#endif

#endif
```

```cpp
#pragma once                       // 非标准但被所有主流编译器支持
static_assert(sizeof(int) == 4, "requires 32-bit int");   // C++11；C 用 _Static_assert
```

宏的每个参数都要加括号，宏体整体也要加括号：

```c
#define SQUARE(x) ((x) * (x))      /* SQUARE(a + b) 展开为 ((a + b) * (a + b)) */
```

宏没有类型检查，能用 `constexpr` 函数替代时应替代。

## 命名空间与链接

```cpp
namespace net {
namespace detail {
int parse(const char *s);
}
}

using net::detail::parse;          // 引入单个名字
namespace alias = net::detail;     // 命名空间别名
```

```cpp
extern "C" {                       // 关闭 C++ 名称修饰
int native_init(const char *path);
}
```

C++ 中未命名的命名空间等价于内部链接，用于替代 `static` 全局函数：

```cpp
namespace {
int helper() { return 0; }
}
```

## JNI 常用语法

```cpp
#include <jni.h>
#include <string>

extern "C" JNIEXPORT jstring JNICALL
Java_com_example_Native_greeting(JNIEnv *env, jobject /* thiz */, jstring name) {
    const char *utf = env->GetStringUTFChars(name, nullptr);
    if (utf == nullptr) {
        return nullptr;            // 分配失败，异常已挂起
    }
    std::string out = std::string("hello, ") + utf;
    env->ReleaseStringUTFChars(name, utf);
    return env->NewStringUTF(out.c_str());
}
```

| 元素 | 写法 |
| --- | --- |
| 静态注册函数名 | `Java_包名_类名_方法名`，包名中的 `.` 换成 `_` |
| 导出声明 | `JNIEXPORT` + 返回类型 + `JNICALL` |
| C 调用形式 | `(*env)->FindClass(env, "...")` |
| C++ 调用形式 | `env->FindClass("...")` |
| 字符串转换 | `GetStringUTFChars` / `ReleaseStringUTFChars` |
| 数组访问 | `Get<Type>ArrayElements` / `Release<Type>ArrayElements` |
| 异常检查 | `ExceptionCheck` / `ExceptionClear` |

完整的类型映射与引用规则见 [[7. JNI 边界语义]]。

## C 与 C++ 差异

| 维度 | C | C++ |
| --- | --- | --- |
| 内存分配 | `malloc` / `free` | `new` / `delete`，或智能指针 |
| 字符串 | `char *` + `'\0'` | `std::string` |
| 类型转换 | 隐式，`(T)x` | `static_cast` / `dynamic_cast` / `reinterpret_cast` |
| 结构体名 | 需 `struct Point` 或 typedef | 直接 `Point` |
| 空指针 | `NULL` | `nullptr` |
| 函数 | 不可重载 | 重载、默认参数、模板 |
| 引用 | 无 | `T &`、`T &&` |
| 泛型 | `void *` + 宏 | 模板 |
| 异常 | 无 | `try` / `catch` / `throw` |
| 命名空间 | 无 | `namespace` |
| 常量表达式 | `#define`、`const` | `constexpr`、`consteval` |
| 变长数组 | C99 可选 | 不支持，用 `std::vector` |

## 常见编译错误

| 错误信息 | 常见原因 |
| --- | --- |
| `expected ';' before ...` | 上一行缺分号；结构体定义后漏分号 |
| `undefined reference to 'foo(int)'` | 缺库、链接顺序、C/C++ 混用未加 `extern "C"` |
| `no matching function for call to ...` | 参数类型或数量不匹配；重载决议失败 |
| `cannot convert 'const char*' to 'char*'` | C++11 起字符串字面量类型为 `const char[N]` |
| `redefinition of ...` | 头文件中定义变量或非 inline 函数 |
| `incomplete type ... used in ...` | 只前置声明未包含完整定义 |
| `invalid use of incomplete type` | 成员访问需要完整类型 |
| `narrowing conversion` | 列表初始化中发生窄化 |
| `no member named ...` | 头文件缺失或命名空间未引入 |
| `use of undeclared identifier` | 拼写、作用域、缺少 include |

## 小结

NDK r30 的可用语言面由三件事界定：Clang 21 的语言特性支持、libc++ 的库特性覆盖、bionic 在最低 API 级别上的符号可用性。工程基线取 C11 与 C++17 可以覆盖官方承诺，C++20 在 r30 上可用但需要显式开启并确认库特性，C23 只建议使用语言层特性。语法速查的价值在于减少查证成本，涉及 ABI、所有权与 JNI 边界的判断仍要以对应章节的规则为准。
