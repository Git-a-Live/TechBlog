命令行程序的输入是字符串数组，输出是标准输出上的文本。把这两端连接起来，需要变量保存状态、分支选择行为、函数拆分逻辑，以及空安全机制保证缺失的输入不会在运行时变成空指针崩溃。

这一节围绕一个命令分发器展开：程序根据第一个参数决定打印帮助、版本信息，还是进入搜索流程；搜索标题既可以来自后续参数，也可以在缺失时从标准输入读取。

## 变量与常量

Dart 的变量声明有四种常见形式，差别在于“是否允许重新赋值”和“值在什么阶段确定”。

```dart
const version = '0.0.1';   // 编译期常量
final name = 'Dartpedia';  // 运行期只赋值一次
var count = 0;             // 可重新赋值，类型由初始值推断
int total = 0;             // 显式声明类型
```

| 声明 | 可重新赋值 | 值确定时机 | 典型用途 |
|------|------------|------------|----------|
| `var` | 是 | 运行时 | 状态会变化的局部变量 |
| `final` | 否，只能赋值一次 | 运行时 | 依赖运行时输入、但之后不再变化的值 |
| `const` | 否 | 编译期 | 字面量常量、编译期配置、`const` 构造的对象 |
| 显式类型 | 取决于是否加 `final`/`const` | 运行时 | 需要明确接口或避免推断歧义 |

`const` 隐含 `final`，但要求更强：初始值必须是编译期常量表达式。字面量、其他 `const` 变量、`const` 构造函数调用、以及由它们组成的算术与字符串运算都满足要求。

```dart
const version = '0.0.1';
const title = 'Dartpedia CLI version $version'; // 合法：编译期可求值

final now = DateTime.now();   // 合法：运行时求值
// const timestamp = DateTime.now(); // 编译错误：不是常量表达式
```

`var` 的类型一旦由初始值推断出来就不再改变。Dart 是静态类型语言，下面的第二次赋值会在编译期报错，而不是运行时才失败：

```dart
var count = 0;
// count = 'one'; // 编译错误：String 不能赋给 int
```

需要接收任意类型时使用 `Object?`，需要放弃静态检查时使用 `dynamic`。两者语义不同：`Object?` 上的操作仍受类型系统约束，`dynamic` 上的调用推迟到运行时解析，应尽量避免。

## 字符串插值

字符串中的 `$identifier` 或 `${expression}` 会被替换为对应值：

```dart
print('Dartpedia CLI version $version');
print('Arguments: ${arguments.length}');
```

`$version` 只适用于简单标识符；表达式、属性访问、方法调用必须使用花括号。字符串本身不可变，拼接、截取都会产生新字符串。

相邻的字符串字面量会自动连接，长文本可以跨行书写：

```dart
const message =
    'The following commands are valid: '
    "'help', 'version', 'search <ARTICLE-TITLE>'";
```

## 列表操作

命令行参数是 `List<String>`，常用的只读操作如下：

| 成员 | 结果 | 边界行为 |
|------|------|----------|
| `isEmpty` / `isNotEmpty` | 是否为空 | 无 |
| `first` / `last` | 首/末元素 | 空列表抛 `StateError` |
| `length` | 元素个数 | 无 |
| `sublist(start, [end])` | 新列表，包含 `[start, end)` | 越界抛 `RangeError`；`start == length` 返回空列表 |
| `join(separator)` | 拼接后的字符串 | 空列表返回空字符串 |
| `contains(element)` | 是否包含 | 使用 `==` 比较 |

命令分发依赖首元素，因此必须先判空再取 `first`：

```dart
if (arguments.isEmpty || arguments.first == 'help') {
  printUsage();
}
```

`||` 是短路运算，左侧为真时不会计算右侧，`first` 不会在空列表上被访问。

取命令之后的参数时，用 `sublist(1)` 排除命令本身：

```dart
final inputArgs = arguments.length > 1 ? arguments.sublist(1) : null;
```

`['search', 'Dart', 'Programming']` 经 `sublist(1)` 得到 `['Dart', 'Programming']`；只有 `['search']` 时返回空列表，因此还需要用长度判断决定是否传 `null`。

## 空安全

Dart 的空安全是“可靠”的：类型系统保证非空类型永远不会是 `null`，可空类型必须显式标注 `?`，并且在使用前处理 `null`。

```dart
List<String>? arguments; // 列表本身可能为 null
String? help;            // 字符串可能为 null
```

可空性表达的是“值的缺失”，不是错误。函数参数用 `List<String>?` 明确声明“可能没有参数”，调用方就必须考虑这种情况；返回类型用 `String?` 表示“可能查不到”，调用方就必须提供回退路径。

处理可空值有三种常用手段：

```dart
// 1. 空值合并：左侧为 null 时取右侧
final title = input ?? '';

// 2. 条件访问：接收者为 null 时整个表达式为 null
final length = title?.length;

// 3. 空断言：断言非 null，否则抛运行时错误
final first = arguments!.first;
```

`??` 只在前者为 `null` 时求值右侧，常用于提供默认值。`?.` 适合链式访问，但会把 `null` 继续向下传递，最终仍需处理。`!` 是向编译器承诺“此处一定非空”，承诺错误会在运行时崩溃，应只在逻辑上已经排除 `null` 的位置使用。

Dart 的流分析（flow analysis）会跟踪变量的赋值与检查，在确定非空的分支里自动把可空类型提升为非空类型：

```dart
void searchWikipedia(List<String>? arguments) {
  if (arguments == null || arguments.isEmpty) {
    return;
  }
  // 此处 arguments 已被提升为 List<String>
  print(arguments.first);
}
```

局部 `final` 变量允许先声明、后在所有分支中赋值一次，编译器会做确定赋值分析（definite assignment）：

```dart
final String articleTitle;

if (arguments == null || arguments.isEmpty) {
  articleTitle = stdin.readLineSync() ?? '';
} else {
  articleTitle = arguments.join(' ');
}

print(articleTitle); // 两条路径都已赋值，合法
```

如果把某个分支的赋值删掉，编译器会直接报“可能未初始化”，而不是等到运行时才暴露。

## 函数

函数把可复用的逻辑从 `main` 中拆出，保持入口只负责分发：

```dart
void printUsage() {
  print(
    "The following commands are valid: "
    "'help', 'version', 'search <ARTICLE-TITLE>'",
  );
}

void searchWikipedia(List<String>? arguments) {
  // ...
}
```

返回类型为 `void` 表示不产生有意义的结果。参数支持三种形式：

```dart
void connect(String host, int port) {}                 // 必选位置参数
void log(String message, [String? prefix]) {}          // 可选位置参数
void configure({required String host, int port = 80}) {} // 命名参数
```

命名参数用 `{}` 包裹，默认可选，加 `required` 变为必填；可选位置参数用 `[]` 包裹，必须位于参数列表末尾。默认值必须是编译期常量。

函数体只有单个表达式时可以用箭头语法：

```dart
String formatVersion(String v) => 'Dartpedia CLI version $v';
```

## 命令分发

最早的分发结构是 `if`/`else if` 链，最后一个 `else` 作为未知命令的兜底：

```dart
void main(List<String> arguments) {
  if (arguments.isEmpty || arguments.first == 'help') {
    printUsage();
  } else if (arguments.first == 'version') {
    print('Dartpedia CLI version $version');
  } else if (arguments.first == 'search') {
    final inputArgs = arguments.length > 1 ? arguments.sublist(1) : null;
    searchWikipedia(inputArgs);
  } else {
    printUsage();
  }
}
```

同一逻辑也可以用 `switch` 表达。Dart 3 的非空 `case` 执行完自动跳到 `switch` 末尾，不需要 `break`；空的 `case` 会继续向下贯穿，用于多个值共享同一段逻辑。

```dart
void main(List<String> arguments) {
  if (arguments.isEmpty) {
    printUsage();
    return;
  }

  switch (arguments.first) {
    case 'help':
      printUsage();
    case 'version':
      print('Dartpedia CLI version $version');
    case 'search':
      final inputArgs = arguments.length > 1 ? arguments.sublist(1) : null;
      searchWikipedia(inputArgs);
    default:
      printUsage();
  }
}
```

`if`/`else` 适合条件少量且带复合判断的场景；`switch` 适合单值对多分支的分发，配合枚举与密封类还能获得穷尽性检查，详见 [[8. 增强枚举与扩展方法|增强枚举]] 与 [[10. JSON 解析与模式匹配|模式匹配]]。

## 标准输入

标题缺失时，从标准输入读取一行：

```dart
import 'dart:io';

void searchWikipedia(List<String>? arguments) {
  final String articleTitle;

  if (arguments == null || arguments.isEmpty) {
    print('Please provide an article title.');
    articleTitle = stdin.readLineSync() ?? '';
  } else {
    articleTitle = arguments.join(' ');
  }

  print('Current article title: $articleTitle');
}
```

`dart:io` 提供文件、目录、套接字与标准输入输出。`stdin.readLineSync()` 的返回值是 `String?`，两种情况下为 `null` 或空串，需要区分：

| 用户操作 | 返回值 |
|----------|--------|
| 输入文本后回车 | 该行文本，不含换行符 |
| 直接回车 | 空字符串 `''` |
| `Ctrl+D`（Unix）或 `Ctrl+Z`（Windows）发送 EOF | `null` |

`?? ''` 把 EOF 折叠为空串，后续逻辑只需判断 `isEmpty`。若要区分“未输入”和“输入为空”，则不能提前折叠：

```dart
final input = stdin.readLineSync();
if (input == null || input.isEmpty) {
  print('No article title provided. Exiting.');
  return;
}
```

参数拼接使用 `join(' ')`，可以把 `['Dart', 'Programming']` 还原为 `"Dart Programming"`，使多词标题在命令行中无需引号也能作为一个整体处理。

## 完整形态

把上述部分组合起来，得到一个可运行的命令分发器：

```dart
import 'dart:io';

const version = '0.0.1';

void main(List<String> arguments) {
  if (arguments.isEmpty || arguments.first == 'help') {
    printUsage();
  } else if (arguments.first == 'version') {
    print('Dartpedia CLI version $version');
  } else if (arguments.first == 'search') {
    final inputArgs = arguments.length > 1 ? arguments.sublist(1) : null;
    searchWikipedia(inputArgs);
  } else {
    printUsage();
  }
}

void searchWikipedia(List<String>? arguments) {
  final String articleTitle;

  if (arguments == null || arguments.isEmpty) {
    print('Please provide an article title.');
    articleTitle = stdin.readLineSync() ?? '';
  } else {
    articleTitle = arguments.join(' ');
  }

  print('Looking up articles about "$articleTitle". Please wait.');
  print('Here ya go!');
  print('(Pretend this is an article about "$articleTitle")');
}

void printUsage() {
  print(
    "The following commands are valid: "
    "'help', 'version', 'search <ARTICLE-TITLE>'",
  );
}
```

`const` 与 `final` 的区分决定了值的生命周期，空安全决定了缺失输入的处理方式，函数与分支决定了命令如何被路由。这三部分构成了后续所有功能的基础：下一节把“假装查询”替换为真实的 HTTP 请求，就需要引入 `Future` 与 `async`/`await`，见 [[3. 异步编程与 Future|异步编程]]。
