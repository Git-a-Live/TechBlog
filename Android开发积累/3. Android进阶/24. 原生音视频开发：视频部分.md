本篇聚焦 `ExoPlayer` 在视频播放场景下的实践，覆盖视频渲染、画面比例、播放控件、自适应码率流、视频轨道选择、字幕与 DRM 等内容。音频播放相关的话题参见[[23. 原生音视频开发：音频部分|音频部分]]。

## 视频渲染

`ExoPlayer` 本身不直接绘制画面，而是将解码后的视频帧输出到指定的 `Surface`。渲染输出的方式分为两类：使用预置的 `PlayerView`，或自行指定 `Surface`。

### 使用 PlayerView

`PlayerView` 是 `ExoPlayer` 预置的播放器视图，内部封装了渲染视频的 `Surface`、显示字幕的 `SubtitleView` 以及播放控制条 `PlayerControlView`。在布局文件中声明并绑定播放器即可：

```xml
<androidx.media3.ui.PlayerView
    android:id="@+id/player_view"
    android:layout_width="match_parent"
    android:layout_height="match_parent" />
```

```kotlin
val playerView = findViewById<PlayerView>(R.id.player_view)
playerView.player = player
```

`PlayerView` 默认使用 `SurfaceView` 渲染视频，性能较好；也可以切换为 `TextureView` 以支持平移、旋转等变换操作（详见「画面比例与缩放」）。

### 自行指定 Surface

对于自行实现播放 UI 的应用，可以把视频渲染到指定的 `SurfaceView`、`TextureView`、`SurfaceHolder` 或裸 `Surface` 上：

```kotlin
// 渲染到 SurfaceView
player.setVideoSurfaceView(surfaceView)

// 渲染到 TextureView
player.setVideoTextureView(textureView)

// 渲染到自定义 Surface
player.setVideoSurface(surface)
```

## 画面比例与缩放

视频的原始宽高比与播放器视图通常不一致，`PlayerView` 通过 `resize_mode` 控制画面的缩放与裁剪方式。取值及含义如下：

+ `fit`（默认）：等比缩放，完整显示画面，可能留黑边；
+ `fill`：拉伸填满视图，可能造成画面变形；
+ `fixed_width` / `fixed_height`：以宽度（或高度）为基准等比缩放，超出部分裁剪；
+ `zoom`：等比放大填满视图，裁剪超出部分。

在 XML 中通过属性配置：

```xml
<androidx.media3.ui.PlayerView
    android:id="@+id/player_view"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    app:resize_mode="zoom" />
```

也可在代码中动态设置：

```kotlin
playerView.resizeMode = AspectRatioFrameLayout.RESIZE_MODE_ZOOM
```

> 说明：`resize_mode` 作用于视图层的画面显示。若需要 `TextureView` 才支持的平移、旋转等视图变换，可通过 `app:surface_type="texture_view"` 切换渲染方式。

## 播放控件

`PlayerView` 内置的 `PlayerControlView` 提供了播放/暂停、进度条、快进快退等常用控件，通过属性控制其显隐与行为：

```xml
<androidx.media3.ui.PlayerView
    android:id="@+id/player_view"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    app:use_controller="true"
    app:show_buffering="when_playing"
    app:controller_layout_id="@layout/custom_player_control_view" />
```

+ `use_controller`：是否显示播放控制条，设为 `false` 可完全隐藏并自行实现；
+ `show_buffering`：缓冲指示器的显示时机，取值 `never`、`when_playing`、`always`；
+ `controller_layout_id`：指定自定义的控制器布局，用于深度定制。

## 自适应码率流

`ExoPlayer` 直接支持 DASH、HLS、SmoothStreaming 等自适应流协议。与普通渐进式媒体不同，自适应流包含多个码率的视频轨道，`ExoPlayer` 会根据当前网络带宽自动切换码率，以保证流畅播放。

播放自适应流需要先引入对应扩展模块：

```kotlin
implementation("androidx.media3:media3-exoplayer-dash:1.11.1")
implementation("androidx.media3:media3-exoplayer-hls:1.11.1")
```

引入后，直接使用流的 URL 构建 `MediaItem` 即可，`DefaultMediaSourceFactory` 会根据 URL 自动识别并创建对应的 `MediaSource`：

```kotlin
val mediaItem = MediaItem.fromUri("https://example.com/video.mpd")
player.setMediaItem(mediaItem)
player.prepare()
player.play()
```

`DefaultTrackSelector` 默认会对同一视频的多码率轨道启用自适应切换（adaptive selection），并根据网络状况动态调整。

## 视频轨道选择

对于包含多分辨率、多码率轨道的媒体，可以通过 `TrackSelectionParameters` 约束视频轨道的选择范围：

```kotlin
player.trackSelectionParameters = player.trackSelectionParameters
    .buildUpon()
    // 限制最大分辨率（单位像素），例如不超过 1280x720
    .setMaxVideoSize(1280, 720)
    // 限制最小分辨率，例如不低于 640x360
    .setMinVideoSize(640, 360)
    .build()
```

`TrackSelectionParameters` 还提供了便捷的预设：

```kotlin
player.trackSelectionParameters = player.trackSelectionParameters
    .buildUpon()
    // 限制为标准清晰度（SD）
    .setMaxVideoSizeSd()
    .build()
```

这通常用于「标清优先」等省流量场景，或根据用户手动选择的分辨率档位动态调整。

## 字幕

`ExoPlayer` 支持内嵌字幕与外挂字幕。外挂字幕通过与 `MediaItem` 绑定的 `SubtitleConfiguration` 旁路加载：

```kotlin
val subtitle = MediaItem.SubtitleConfiguration.Builder(subtitleUri)
    // 字幕格式，.srt 对应 APPLICATION_SUBRIP
    .setMimeType(MimeTypes.APPLICATION_SUBRIP)
    // 字幕语言
    .setLanguage("zh")
    .build()

val mediaItem = MediaItem.Builder()
    .setUri(videoUri)
    .setSubtitleConfigurations(listOf(subtitle))
    .build()

player.setMediaItem(mediaItem)
player.prepare()
```

对于含多语言内嵌字幕的媒体，同样通过 `TrackSelectionParameters` 设置首选字幕语言：

```kotlin
player.trackSelectionParameters = player.trackSelectionParameters
    .buildUpon()
    .setPreferredTextLanguage("zh")
    .build()
```

`PlayerView` 内置的 `SubtitleView` 会自动渲染选中的字幕轨道，无需额外配置。

## DRM

对于受 DRM 保护的媒体，`ExoPlayer` 基于 Android 的 `MediaDrm` 提供支持。常见的 Widevine 方案在不同 Android 版本上的最低要求如下：

+ Widevine "cenc"：Android 4.4（API 19）起，支持 DASH 与 HLS（仅 FMP4）；
+ Widevine "cbcs"：Android 7.1（API 25）起，支持 DASH 与 HLS（仅 FMP4）。

### 基础配置

构建 `MediaItem` 时通过 `DrmConfiguration` 指定 DRM 系统与许可证服务器：

```kotlin
val drmConfiguration = MediaItem.DrmConfiguration.Builder(C.WIDEVINE_UUID)
    // 许可证服务器地址
    .setLicenseUri(licenseUri)
    // 是否需要多会话（用于密钥轮换或多密钥内容）
    .setMultiSession(true)
    .build()

val mediaItem = MediaItem.Builder()
    .setUri(videoUri)
    .setDrmConfiguration(drmConfiguration)
    .build()
```

`ExoPlayer` 会据此构建默认的 `DefaultDrmSessionManager`，满足绝大多数场景。

### 离线密钥与自定义会话管理器

离线播放可以使用本地存储的密钥集：

```kotlin
val drmConfiguration = MediaItem.DrmConfiguration.Builder(C.WIDEVINE_UUID)
    .setLicenseUri(licenseUri)
    // 指定离线密钥集 ID
    .setKeySetId(offlineKeySetId)
    .build()
```

若需要完全自定义 DRM 会话管理，可向 `DefaultMediaSourceFactory` 注入自定义的 `DrmSessionManager`：

```kotlin
val customDrmSessionManager: DrmSessionManager = CustomDrmSessionManager()
val mediaSourceFactory = DefaultMediaSourceFactory(context)
    .setDrmSessionManagerProvider { customDrmSessionManager }

val player = ExoPlayer.Builder(context)
    .setMediaSourceFactory(mediaSourceFactory)
    .build()
```

## 屏幕常亮

视频播放过程中，应防止屏幕因无交互而自动熄灭。最简单的方式是在承载播放器的视图上设置 `keepScreenOn`：

```xml
<androidx.media3.ui.PlayerView
    android:id="@+id/player_view"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:keepScreenOn="true" />
```

至此，视频播放的完整链路（渲染 → 比例 → 控件 → 自适应流 → 轨道 → 字幕 → DRM）已经贯通。
