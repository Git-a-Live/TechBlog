TTS（Text-to-Speech，文字转语音）用于把文本合成为语音并朗读或输出成音频文件。Android 通过 `android.speech.tts.TextToSpeech` 提供该能力。

一个关键认知：**TTS 不是直接操作音频硬件**，而是调用系统中安装的**语音合成引擎**（Google 语音服务、厂商内置引擎、讯飞等第三方引擎）。应用把文本交给引擎，由引擎完成合成与播放。引擎可以是在线的（需联网）也可以是离线的（本地语言包）。

## 权限说明

`TextToSpeech` 本身**不需要任何运行时权限**（与录音不同，无需弹窗授权）。但有两处 Manifest 配置需要注意：

```xml
<!-- 若使用的 TTS 引擎需要联网合成，则需声明网络权限 -->
<uses-permission android:name="android.permission.INTERNET" />

<!-- Android 11（API 30）起，包可见性限制会导致 getEngines() 返回空列表，
     必须显式声明查询 TTS 服务 -->
<queries>
    <intent>
        <action android:name="android.intent.action.TTS_SERVICE" />
    </intent>
</queries>
```

## 初始化

`TextToSpeech` 的初始化是**异步**的，构造时传入 `OnInitListener`，在 `onInit` 回调里确认成功后才能真正使用：

```kotlin
private var tts: TextToSpeech? = null

private fun initTts() {
    tts = TextToSpeech(this) { status ->
        if (status == TextToSpeech.SUCCESS) {
            // 初始化成功，接着设置语言
            setLanguage()
        } else {
            // 初始化失败
        }
    }
}
```

> 必须在 `onInit` 回调返回 `SUCCESS` 之后才能调用 `speak()` 等操作，在此之前调用行为未定义。真正的引擎绑定发生在主线程下一次调度，不要在回调外或其它线程抢先调用。

## 设置语言与发音参数

初始化成功后，先设置语言，再按需调整语速、音调：

```kotlin
private fun setLanguage() {
    val result = tts?.setLanguage(Locale.CHINA) ?: return
    when (result) {
        TextToSpeech.LANG_MISSING_DATA,
        TextToSpeech.LANG_NOT_SUPPORTED -> {
            // 语言数据缺失或不支持，需引导用户下载语言包
        }
        else -> {
            // 语言可用（LANG_AVAILABLE 等）
        }
    }

    tts?.setSpeechRate(1.0f)   // 语速，1.0 为正常，<1 变慢、>1 变快
    tts?.setPitch(1.0f)        // 音调，1.0 为正常
}
```

API 21+ 还可以用 `setVoice()` 切换具体音色（男声/女声/方言），用 `getVoices()` 枚举可用音色：

```kotlin
val voices = tts?.voices                    // 可用音色列表
tts?.voice = voices?.firstOrNull()          // 选择某个 Voice
```

## 朗读文本

核心方法是 `speak()`，参数依次为文本、队列模式、附加参数、utteranceId：

```kotlin
private fun speak(text: String) {
    // QUEUE_FLUSH：清空队列立即朗读；QUEUE_ADD：追加到队列末尾
    tts?.speak(text, TextToSpeech.QUEUE_FLUSH, null, "utterance_id_1")
}
```

> `utteranceId` 是本次朗读的唯一标识，供进度回调关联使用。若传 `null`，`UtteranceProgressListener` 不会收到对应的回调。

## 合成到文件

`speak()` 是直接朗读，若想生成音频文件，用 `synthesizeToFile()`：

```kotlin
private fun synthesizeToFile(text: String, outputFile: File) {
    val result = tts?.synthesizeToFile(
        text,
        null,              // 附加参数
        outputFile,        // 输出文件
        "utterance_id_2"   // utteranceId
    )
    if (result == TextToSpeech.SUCCESS) {
        // 合成成功，audioFile 为生成的音频文件
    }
}
```

## 监听合成进度

用 `UtteranceProgressListener` 监听朗读/合成的开始、完成、出错。注意旧的 `setOnUtteranceCompletedListener` 已废弃：

```kotlin
tts?.setOnUtteranceProgressListener(object : UtteranceProgressListener() {
    override fun onStart(utteranceId: String) {
        // 开始合成/朗读
    }

    override fun onDone(utteranceId: String) {
        // 完成
    }

    override fun onError(utteranceId: String, errorCode: Int) {
        // 出错，errorCode 为 TextToSpeech.ERROR_* 之一
    }
})
```

> `onError(utteranceId: String)` 的单参重载已废弃，应实现带 `errorCode` 的双参版本。回调可能在多线程触发，需注意线程安全。

## 引擎选择

系统可能装有多个 TTS 引擎（Google、厂商、第三方），可通过 `getEngines()` 枚举、`setEngineByPackageName()` 切换：

```kotlin
// 枚举可用引擎（Android 11+ 需先声明 <queries>，否则可能返回空）
val engines = tts?.engines
val defaultEngine = tts?.defaultEngine

// 切换到指定引擎（需重新初始化生效）
tts?.setEngineByPackageName("com.google.android.tts")
```

> **Android 11（API 30）包可见性问题**：若 Manifest 未声明 `<queries>` 查询 `TTS_SERVICE`，`getEngines()` 会返回空列表、`defaultEngine` 可能为 null，系统静默回退到某个引擎，导致「语言不支持」等难以排查的问题。

## 资源释放

不再使用 TTS 时应及时释放引擎资源：

```kotlin
override fun onDestroy() {
    super.onDestroy()
    tts?.stop()      // 停止当前朗读
    tts?.shutdown()  // 释放引擎资源
    tts = null
}
```

> `stop()` 只停止当前朗读；`shutdown()` 才是真正释放引擎，必须在界面销毁时调用，否则引擎资源会持续占用。

## 注意事项

- **音频焦点**：TTS 朗读时建议设置合理的 `setAudioAttributes()`（如 `USAGE_ASSISTANCE_ACCESSIBILITY`），以便系统正确处理与音乐播放等的焦点竞争。
- **引擎能力差异**：不同引擎对语言、音色、离线包的支持差异很大，应做好「语言不可用 / 引擎缺失」的降级与引导。
- **在线 vs 离线**：在线引擎依赖网络且可能有延迟，离线引擎需本地语言包。应根据业务场景取舍，并处理无网络时的失败。
