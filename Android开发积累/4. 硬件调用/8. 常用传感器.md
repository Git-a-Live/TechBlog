Android 通过 `android.hardware` 包下的**传感器框架**（Sensor Framework）统一访问设备上的各类传感器：加速度计、陀螺仪、磁力计、光感、接近传感器等。核心类有三个：

- **`SensorManager`**：传感器系统的入口，用于获取传感器、注册/注销监听；
- **`Sensor`**：代表一个具体的传感器，描述其类型、量程、分辨率等；
- **`SensorEvent`**：一次传感器读数，数据放在 `values` 数组里。

## 权限说明

绝大多数传感器（加速度计、陀螺仪、磁力计、光线、接近等）**不需要任何权限**。只有少数特殊传感器需要声明：

```xml
<!-- 身体传感器（心率、血压、血氧等）：Android 4.4W（API 20）起 -->
<uses-permission android:name="android.permission.BODY_SENSORS" />
<!-- 活动识别（计步、步行检测等）：Android 10（API 29）起 -->
<uses-permission android:name="android.permission.ACTIVITY_RECOGNITION" />
```

> 从 **Android 13（API 33）** 起，若应用需要在**后台**访问身体传感器（如心率），还需额外声明 `BODY_SENSORS_BACKGROUND` 权限，且必须与 `BODY_SENSORS` **分步申请**（一次性同时请求会被系统忽略）。

## 获取传感器

```kotlin
private lateinit var sensorManager: SensorManager

override fun onCreate(savedInstanceState: Bundle?) {
    super.onCreate(savedInstanceState)
    sensorManager = getSystemService(SensorManager::class.java)

    // 获取指定类型的传感器
    val accelerometer = sensorManager.getDefaultSensor(Sensor.TYPE_ACCELEROMETER)
    // 获取设备上全部传感器
    val allSensors: List<Sensor> = sensorManager.getSensorList(Sensor.TYPE_ALL)
}
```

> `getDefaultSensor()` 可能返回 `null`（设备无该传感器），使用前需判空。

## 注册监听

实现 `SensorEventListener` 接口，通过 `registerListener()` 注册，并指定**采样率**：

```kotlin
private val sensorListener = object : SensorEventListener {
    override fun onSensorChanged(event: SensorEvent) {
        when (event.sensor.type) {
            Sensor.TYPE_ACCELEROMETER -> {
                // values[0]/[1]/[2] 分别为 X/Y/Z 轴加速度，单位 m/s²
            }
            Sensor.TYPE_GYROSCOPE -> {
                // 角速度，单位 rad/s
            }
        }
    }

    override fun onAccuracyChanged(sensor: Sensor, accuracy: Int) {
        // 精度发生变化时回调
    }
}

private fun startListening(accelerometer: Sensor?) {
    accelerometer?.let {
        sensorManager.registerListener(sensorListener, it, SensorManager.SENSOR_DELAY_GAME)
    }
}
```

### 采样率

`registerListener()` 的第三个参数控制采样频率，是**功耗**与**实时性**的权衡。数值越大采样越快、越耗电：

| 采样率常量 | 说明 | 大致间隔 |
| :---: | :---: | :---: |
| `SENSOR_DELAY_NORMAL` | 屏幕方向等普通用途 | ~200ms |
| `SENSOR_DELAY_UI` | UI 交互 | ~60ms |
| `SENSOR_DELAY_GAME` | 游戏、体感 | ~20ms |
| `SENSOR_DELAY_FASTEST` | 尽可能快 | 最快，最耗电 |

## 生命周期管理

传感器是持续的耗电来源，**必须**在界面不可见时注销监听：

```kotlin
override fun onResume() {
    super.onResume()
    startListening(sensorManager.getDefaultSensor(Sensor.TYPE_ACCELEROMETER))
}

override fun onPause() {
    super.onPause()
    // 注销全部监听
    sensorManager.unregisterListener(sensorListener)
}
```

## 常用传感器类型

| 常量 | 说明 | values 含义 |
| :---: | :---: | :---: |
| `TYPE_ACCELEROMETER` | 加速度计 | X/Y/Z 轴加速度（m/s²） |
| `TYPE_GYROSCOPE` | 陀螺仪 | X/Y/Z 轴角速度（rad/s） |
| `TYPE_MAGNETIC_FIELD` | 磁力计（指南针） | X/Y/Z 轴磁场强度（μT） |
| `TYPE_LIGHT` | 光线传感器 | 光照强度（lux） |
| `TYPE_PROXIMITY` | 接近传感器 | 距离（cm） |
| `TYPE_PRESSURE` | 气压计 | 气压（hPa） |
| `TYPE_GRAVITY` | 重力传感器 | X/Y/Z 轴重力分量 |
| `TYPE_STEP_COUNTER` | 计步器 | 累计步数 |
| `TYPE_HEART_RATE` | 心率传感器 | 心率（次/分），需 `BODY_SENSORS` |

## 注意事项

- **坐标系**：传感器返回值基于设备的默认坐标系统（X 向右、Y 向上、Z 垂直屏幕向外），与屏幕方向无关，需自行换算。
- **后台限制**：应用进入后台后，普通传感器事件的投递可能被延迟或停止；需要后台持续采集时，应使用前台服务。
- **去抖动与滤波**：原始数据（尤其陀螺仪、磁力计）含噪声，实际使用常需低通滤波或结合多个传感器做融合（如用 `SensorManager.getRotationMatrix()` 求方向）。
- **及时释放**：`unregisterListener()` 是硬性要求，否则会造成无谓的电量消耗。
