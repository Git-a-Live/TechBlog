本笔记聚焦**网络硬件的访问**——即如何读取、操作设备上的 Wi-Fi、移动蜂窝网络等硬件能力与连接状态，**不涉及**网络编程（HTTP/套接字/OkHttp 等应用层通信）。

Android 设备的网络硬件主要有三类：**Wi-Fi（WLAN）**、**移动蜂窝网络（SIM/基带）**、以及少量的**以太网**。对应的核心 API 分别是 `WifiManager`、`TelephonyManager`、`ConnectivityManager`（连接状态监测）。

> 蓝牙与 NFC 本质上也是无线通信硬件，但已单独成篇，见 [[1. 蓝牙]] 与 [[6. NFC]]，本笔记不再重复。

## Wi-Fi 硬件访问

### 权限

```xml
<!-- 读取 Wi-Fi 状态（normal 级） -->
<uses-permission android:name="android.permission.ACCESS_WIFI_STATE" />
<!-- 修改 Wi-Fi 配置（normal 级） -->
<uses-permission android:name="android.permission.CHANGE_WIFI_STATE" />
<!-- 读取网络状态（连接监测必需，normal 级） -->
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
<uses-permission android:name="android.permission.CHANGE_NETWORK_STATE" />
<!-- 扫描附近热点需要定位权限（危险级） -->
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
<!-- Android 13（API 33）+：附近 Wi-Fi 设备，可替代定位权限用于部分 Wi-Fi 操作 -->
<uses-permission android:name="android.permission.NEARBY_WIFI_DEVICES" />
```

获取入口：

```kotlin
val wifiManager = applicationContext.getSystemService(WifiManager::class.java)
```

### 读取连接信息与信号强度

```kotlin
val info = wifiManager.connectionInfo
val ssid = info.ssid                       // 当前连接的 SSID
val rssi = info.rssi                       // 信号强度（dBm，负数，-50 强 / -90 弱）
val level = wifiManager.calculateSignalLevel(rssi, 5)  // 转成 0~4 格信号等级
```

### 扫描附近热点

```kotlin
// startScan() 是异步的，结果通过广播 SCAN_RESULTS_AVAILABLE_ACTION 返回
wifiManager.startScan()

// 在 BroadcastReceiver 里监听结果
// val results = wifiManager.scanResults  // List<ScanResult>，含 SSID/BSSID/level
```

### 连接 / 建议网络（Android 10+）

Android 10 起，应用无法直接操控 Wi-Fi 网络列表，官方推荐用 `WifiNetworkSuggestion` 提供网络建议，由系统决定是否连接：

```kotlin
val suggestion = WifiNetworkSuggestion.Builder()
    .setSsid("MyWiFi")
    .setWpa2Passphrase("password")
    .build()

val status = wifiManager.addNetworkSuggestions(listOf(suggestion))
```

### 版本变化（重要）

Wi-Fi 相关 API 自 Android 10 起收紧明显，是易错高发区：

| 版本 | 关键变化 |
| :---: | :---: |
| Android 10（API 29） | `setWifiEnabled()` 失效（无法开关 Wi-Fi）；`getScanResults()`/`getConnectionInfo()` 需定位权限；`getConfiguredNetworks()` 返回空；`addNetwork()`/`enableNetwork()` 失效 |
| Android 11（API 30） | 后台调用连接相关 API 受限 |
| Android 13（API 33） | 新增 `NEARBY_WIFI_DEVICES` 运行时权限，管理附近设备通信；扫描可不再依赖定位权限 |

> 结论：现代应用**不能**静默开关 Wi-Fi、不能直接配置网络，只能「建议」网络并让用户在系统弹窗中确认。需要提示用户开关 Wi-Fi 时，应跳转系统设置面板。

## 移动蜂窝网络硬件（TelephonyManager）

### 权限

```xml
<!-- 读取 SIM、运营商、信号等（危险级） -->
<uses-permission android:name="android.permission.READ_PHONE_STATE" />
<!-- API 26+ 提供部分受限信息的 normal 级替代 -->
<uses-permission android:name="android.permission.READ_BASIC_PHONE_STATE" />
```

获取入口：

```kotlin
val telephonyManager = getSystemService(TelephonyManager::class.java)
```

### SIM 卡信息

```kotlin
val simState = telephonyManager.simState          // SIM_STATE_READY / ABSENT 等
val operatorName = telephonyManager.simOperatorName   // 运营商名称（如「中国移动」）
val countryIso = telephonyManager.simCountryIso       // 归属国家码（如 cn）
```

### 网络类型

```kotlin
// getNetworkType() 已于 API 30 废弃，改用 getDataNetworkType()
val dataNetworkType = telephonyManager.dataNetworkType
// NETWORK_TYPE_LTE = 4G，NETWORK_TYPE_NR = 5G
```

### 信号强度

```kotlin
val signalStrength = telephonyManager.signalStrength
val level = signalStrength.level   // 0~4 格
val dbm = signalStrength.dbm       // dBm 值
```

### 监听信号变化

`PhoneStateListener` 已于 API 31 废弃，改用 `TelephonyCallback`：

```kotlin
val callback = object : TelephonyCallback(), TelephonyCallback.SignalStrengthsListener {
    override fun onSignalStrengthsChanged(signalStrength: SignalStrength) {
        // 信号强度变化
    }
}
// 注册（需先有 READ_PHONE_STATE 权限）
telephonyManager.registerTelephonyCallback(ContextCompat.getMainExecutor(this), callback)
// 注销
telephonyManager.unregisterTelephonyCallback(callback)
```

> 双卡设备需配合 `SubscriptionManager` 按 SubId 区分，对每个活跃订阅分别调用 `createForSubscriptionId()` 获取对应的 `TelephonyManager`。

## 连接状态监测（ConnectivityManager）

`ConnectivityManager` 用于监听「当前是否有可用网络、是什么网络、能力如何」。注意 `NetworkInfo` 已废弃，现代写法用 `Network` + `NetworkCapabilities`。

```kotlin
val connectivityManager = getSystemService(ConnectivityManager::class.java)

val callback = object : ConnectivityManager.NetworkCallback() {
    override fun onAvailable(network: Network) {
        // 网络可用
    }

    override fun onLost(network: Network) {
        // 网络丢失
    }

    override fun onCapabilitiesChanged(network: Network, caps: NetworkCapabilities) {
        val isWifi = caps.hasTransport(NetworkCapabilities.TRANSPORT_WIFI)
        val isCellular = caps.hasTransport(NetworkCapabilities.TRANSPORT_CELLULAR)
        val hasInternet = caps.hasCapability(NetworkCapabilities.NET_CAPABILITY_INTERNET)
        val isValidated = caps.hasCapability(NetworkCapabilities.NET_CAPABILITY_VALIDATED)
    }
}

// 监听默认网络（当前用于上网的网络）
connectivityManager.registerDefaultNetworkCallback(callback)
// 不再需要时注销，避免泄漏
connectivityManager.unregisterNetworkCallback(callback)
```

`NetworkCapabilities` 关键判断项：

| 方法 | 说明 |
| :---: | :---: |
| `hasTransport(TRANSPORT_WIFI / CELLULAR / ETHERNET / BLUETOOTH)` | 判断传输介质 |
| `hasCapability(NET_CAPABILITY_INTERNET)` | 是否声明可访问互联网 |
| `hasCapability(NET_CAPABILITY_VALIDATED)` | 是否已通过系统连通性验证 |

## 其他网络硬件

- **以太网（Ethernet）**：通过 `EthernetManager` 访问，仅少数带网口的设备（机顶盒、车机）支持，且属于 `@SystemApi`，普通第三方应用基本不可用。
- **蓝牙 / NFC**：见 [[1. 蓝牙]] 与 [[6. NFC]]。
