[ZXing](https://github.com/zxing/zxing)是Google开源的一个1D/2D条码图像处理库，使用Java实现，可支持多种格式的1D/2D条码。它包含了联系到其他语言的端口。ZXing可以实现使用手机的内置摄像头完成条码的扫描及解码。ZXing的名字来源于“zebra crossing”，直译过来就是斑马条纹，所以项目的Logo也是一匹斑马。

ZXing只提供了基本的条码生成识别功能，如果想满足开发需求，可能需要自行封装。按照开发团队的说法：

> The project is in maintenance mode, meaning, changes are driven by contributed patches. Only bug fixes and minor enhancements will be considered. ...There is otherwise no active development or roadmap for this project. It is "DIY".
> 
> 本项目处于维护模式，即只有提交的补丁会引起项目变化——除bug修复和主要的功能增强外，其他提交都不考虑。……此外，本项目也没有什么活跃的开发计划或路线图，开发者可DIY自行封装。

限于篇幅，这里只介绍二维码（QR Code）的生成和识别。

## 依赖库导入

ZXing支持`.jar`文件直接导入，不过Google在Maven Center上已经提供了[远程依赖](https://mvnrepository.com/artifact/com.google.zxing/core)方式，所以Android开发中使用远程依赖更为方便：

```groovy
dependencies {
    implementation 'com.google.zxing:core:${specified_version}'
}
```

> 注：ZXing 核心库（core）最新稳定版本为 3.5.x，且项目处于维护模式、仅接受 bug 修复与小规模增强。

由于ZXing有生成、识别条码的功能，因此集成使用时必须配置相机和存储等权限：

```xml
<uses-permission android:name="android.permission.CAMERA" />
<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" />

<uses-feature android:name="android.hardware.camera" />
<uses-feature android:name="android.hardware.camera.autofocus" />
```

在Android 6.0或更高版本的系统上，还需要配置动态权限获取的业务逻辑。

## 基本使用

### 生成二维码图片

首先要设置生成二维码所需的重要参数：
```kotlin
// 用Hashtable类型设置二维码参数
val qrParam = Hashtable<EncodeHintType, Any>().apply {
    // 设置二维码纠错级别，这里选择最高级别H
    put(EncodeHintType.ERROR_CORRECTION, ErrorCorrectionLevel.H)
    // 设置字符编码方式
    put(EncodeHintType.CHARACTER_SET, Charsets.UTF_8.name())
}
```

接着构建BitMatrix类型对象：
```kotlin
// 将内容转换成一个具有特定尺寸的比特矩阵，条码格式设置为BarcodeFormat.QR_CODE，即二维码
val bitMatrix = MultiFormatWriter().encode(content, BarcodeFormat.QR_CODE, width, height, qrParam)
```

然后将BitMatrix转换成一维数组：
```kotlin
// 利用Kotlin扩展函数为BitMatrix对象提供转换一维数组的功能
fun BitMatrix.generateQRData(): IntArray {
    val data = IntArray(width * height)
    for (y in 0 until height) {
        for (x in 0 until width) {
            // 在这里设置像素点颜色
            data[y * width + x] = if (get(x, y)) Color.BLACK else Color.WHITE
        }
    }
    return data
}
```

最后利用一维数组的数据生成Bitmap图片：
```kotlin
// BitMatrix对象转换成一维数组
val data = bitMatrix.generateQRData()
// 创建一张bitmap图片，采用最高图片效果ARGB_8888
val bitmap = Bitmap.createBitmap(bitMatrix.width, bitMatrix.height, Bitmap.Config.ARGB_8888).apply {
    // 传入二维码颜色数组，生成图片颜色
    setPixels(data, 0, width, 0, 0, width, height) 
}
```

至此，利用特定内容生成二维码图片的流程已经基本完成（类似下图所示），只要将生成的Bitmap图片传递给ImageView控件就可以展示了。

有些二维码的中心位置还会有图标，以下介绍如何为二维码设置中心图标。首先需将图标转换为 Bitmap 对象（转换过程略），然后进行以下初始化操作：
```kotlin
// 利用Kotlin扩展函数为Bitmap类型的中心图标提供初始化功能
fun Bitmap.initPortrait(portraitSize: Int): Bitmap? {
    var bitmap: Bitmap? = null
    try {
        val matrix = Matrix().apply {
            setScale(portraitSize * 1F  / width, portraitSize * 1F / height)
        }
        bitmap = Bitmap.createBitmap(this, 0, 0, width, height, matrix, true)
    }
    return bitmap
}
```

接着开始为之前生成的二维码图片添加中心图标：
```kotlin
// 利用Kotlin扩展函数为二维码的Bitmap图片提供绘制中心图标的功能
fun Bitmap.createQRCodeBitmapWithPortrait(qrCodeSize: Int, portraitSize: Int, portrait: Bitmap) {
    portrait.initPortrait(portraitSize)?.let {
        val left = (qrCodeSize - it.width) / 2
        val right = left + it.width
        val top = (qrCodeSize - it.height) / 2
        val bottom = top + it.height
        // 设置图标要显示的位置，即居中显示
        val rect = Rect(left, top, right, bottom)
        // 取得二维码图片上的画笔，即要在二维码图片上绘制图标
        val canvas = Canvas(this)
        // 设置要绘制的图标范围大小
        val rect2 = Rect(0, 0, it.width, it.height)
        // 开始绘制
        canvas.drawBitmap(it, rect2, rect, null)
    }
}
```

在上述流程完成之后，二维码就添加上了中心图标，类似下图所示：

### 识别二维码内容

识别二维码需要先配置以下参数：
```kotlin
// 设置二维码读取配置参数
val readerParam = EnumMap<DecodeHintType, Any>(DecodeHintType::class.java).apply {
    // 配置优化精度
    put(DecodeHintType.TRY_HARDER, true)
    // 配置解码所使用的编码格式
    put(DecodeHintType.CHARACTER_SET, Charsets.UTF_8)
}
```

接着创建二维码解析功能所需的核心对象——解析器：
```kotlin
val qrReader = QRCodeReader()
```

然后对转换成Bitmap的二维码图片进行处理：
```kotlin
// 定义一个整型数组，长度为转换成Bitmap图片的长度 ✖️ 宽度
val array = IntArray(bitmap.width * bitmap.height)

// 将Bitmap的像素点全部导入到刚才定义好的数组
bitmap.getPixels(array, 0, width, 0, 0, width, height)

// 将Bitmap转换成BinaryBitmap
val binaryBitmap = BinaryBitmap(HybridBinarizer(RGBLuminanceSource(bitmap.width, bitmap.height, array)))
```

最后传给二维码解析器进行解析，将内容解析出来：
```kotlin
val content = qrReader.decode(binaryBitmap, readerParam).text
```

至此，利用ZXing已经可以开发出最基本的二维码生成与识别功能。

## 现状与替代方案

### 现状：最常用，但已进入维护模式

ZXing是目前使用最广泛的开源条码库——它被移植到Java、JavaScript、C++、Python等多种语言，几乎覆盖所有常见1D/2D条码格式，甚至包括MaxiCode、GS1 DataBar等冷门格式。但在Android新项目中，ZXing的"扫描"职能正越来越多地被Google官方方案取代；而"生成二维码"这一职能，ZXing的core库依然是最通用、最稳定的选择之一。

### 替代与衍生框架

#### Google ML Kit Barcode Scanning

[ML Kit Barcode Scanning](https://developers.google.com/ml-kit/vision/barcode-scanning)是Google官方提供的条码扫描方案，基于设备端机器学习，免费（但闭源）。相比ZXing：

+ **性能更优**：扫描速度通常快于ZXing，对弱光、模糊、损坏码的鲁棒性更好；
+ **开箱即用**：内置对URL、Wi-Fi、vCard、日历、电话、地理坐标等结构化数据的解析；
+ **官方生态**：与CameraX深度集成，是当前Android扫码的主流推荐。

代价是：格式覆盖不如ZXing（不支持MaxiCode、GS1 DataBar、Micro QR等冷门格式），且闭源、无法定制内部算法。

集成示例：

```kotlin
// 依赖（二选一）
// implementation("com.google.mlkit:barcode-scanning:17.3.0")                 // 模型打包进应用（约 2.4MB）
// implementation("com.google.android.gms:play-services-mlkit-barcode-scanning:18.3.1") // 经 Play 服务动态下载（约 200KB）

// 1. 配置扫码器（只扫 QR，速度更快）
val options = BarcodeScannerOptions.Builder()
    .setBarcodeFormats(Barcode.FORMAT_QR_CODE)
    .build()
val scanner = BarcodeScanning.getClient(options)

// 2. 在 CameraX 的 ImageAnalysis 中逐帧处理
imageAnalysis.setAnalyzer(cameraExecutor) { imageProxy ->
    val mediaImage = imageProxy.image ?: return@setAnalyzer
    val image = InputImage.fromMediaImage(mediaImage, imageProxy.imageInfo.rotationDegrees)
    scanner.process(image)
        .addOnSuccessListener { barcodes ->
            for (barcode in barcodes) {
                barcode.rawValue?.let { raw -> /* 拿到扫码结果 */ }
            }
        }
        .addOnCompleteListener { imageProxy.close() }
}
```

#### ZXingLite

[ZXingLite](https://github.com/jenly1314/ZXingLite)是目前最活跃、最受欢迎的ZXing Kotlin封装之一。它在ZXing基础上补齐了ZXing缺失的"相机预览 + 扫描框 + 扫码UI"这一层，内置微信线条式、支付宝网格式扫描框，几句代码即可集成扫码功能，仍在持续维护。

集成示例（继承`BarcodeCameraScanActivity`，几句代码完成扫码）：

```kotlin
// 依赖（v3.4.0+ 要求 compileSdk ≥ 35）
implementation("com.github.jenly1314:zxing-lite:3.5.0")

class ScanActivity : BarcodeCameraScanActivity() {
    override fun getLayoutId(): Int = R.layout.activity_scan

    override fun createAnalyzer(): Analyzer? {
        val decodeConfig = DecodeConfig()
            .setHints(DecodeFormatManager.QR_CODE_HINTS) // 只扫二维码，效率更高
            .setFullAreaScan(false)                      // 只识别扫描框区域
            .setAreaRectRatio(0.8f)
        return MultiFormatAnalyzer(decodeConfig)
    }

    override fun onScanResultCallback(result: AnalyzeResult) {
        cameraScan.setAnalyzeImage(false)               // 停止分析
        val intent = Intent()
        intent.putExtra(CameraScan.SCAN_RESULT, result.result.text)
        setResult(RESULT_OK, intent)
        finish()
    }
}
```

此外，`CodeUtils`提供无需相机的生成与解析：

```kotlin
CodeUtils.createQRCode(content, 600, logo)                              // 生成二维码（可带 logo）
CodeUtils.createBarCode(content, BarcodeFormat.CODE_128, 800, 200)      // 生成条形码
CodeUtils.parseCode(bitmap)                                             // 从图片解析条码/二维码
```

#### BGAQRCode-Android（流行的老牌封装）

[BGAQRCode-Android](https://github.com/bingoogolapple/BGAQRCode-Android)是另一个非常流行的封装（8k+ stars），同时封装了ZXing与ZBar两个解码后端，支持相册识别、带logo二维码生成、微博/微信/QQ扫描样式。但需注意其最新正式版本v1.0.8发布于2016年，已多年未发版，新项目不宜作为首选。

#### 商业SDK

对扫描性能与可靠性有极致要求的场景（物流、工业等），Scandit、Dynamsoft、Scanbot等商业SDK在复杂环境下表现更优，但需付费。

### 选型建议

+ **Android新项目的"扫描"**：优先Google ML Kit（配合CameraX），性能与生态最佳；
+ **跨平台 / 格式最全 / 需要开源**：ZXing仍是覆盖最广的选择；
+ **只想快速集成扫码UI**：ZXingLite等Kotlin封装最省事；
+ **二维码"生成"**：ZXing core依然是最通用、最稳定的开源选择。
