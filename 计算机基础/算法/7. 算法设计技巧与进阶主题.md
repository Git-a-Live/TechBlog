本章汇总通用的**算法设计范式**与进阶主题。面对一个复杂问题，这些范式提供了系统化的解题思路；而摊还分析、NP 完全性、KNN 等主题则拓展了算法分析的视野。

## 分治算法（Divide and Conquer）

### 思想

分治法将问题**递归地**分解为若干规模更小的子问题，分别求解后再**合并**为原问题的解。三个步骤：

1. **分解**：将原问题拆分为若干子问题。
2. **解决**：递归求解子问题（子问题足够小时直接求解）。
3. **合并**：合并子问题的解得到原问题的解。

### 典型例子

- **归并排序**：分解到单元素，再两两合并有序子序列。
- **快速排序**：按基准划分后递归排序两侧。
- **二分查找**：每次排除一半。
- **最近点对问题**：将点集按 x 坐标对半分，跨中线的最短距离在窄条带内计算。
- **矩阵快速幂**、**大整数乘法（Karatsuba）**。

**分治运行时间**通常可用**主定理（Master Theorem）**求解：$T(n) = aT(n/b) + f(n)$。

## 贪心算法（Greedy）

### 思想

贪心法在每一步都做出**当前看起来最优**的选择，希望局部最优能导出全局最优。贪心**不回溯**、不回头修改，因此速度快，但**并非所有问题都适用**。

### 适用条件

- **贪心选择性质**：局部最优选择能导向全局最优解。
- **最优子结构**：问题的最优解包含子问题的最优解。

### 典型例子

- **Dijkstra、Prim、Kruskal**：每步选最短边/最小权边。
- **哈夫曼编码**：每次合并两个最小频率节点。
- **活动选择 / 区间调度**：优先选择结束最早的活动。
- **找零问题**（硬币面额满足特定条件时）。

### 当贪心失败时

贪心无法保证最优时（如**0-1 背包问题**），应改用**动态规划**；若问题本身无高效解（NP 完全），贪心常作为**近似算法**求可行解（如集合覆盖问题）。

## 动态规划（Dynamic Programming）

### 思想

动态规划适用于具有以下两个特征的问题：

1. **最优子结构**：问题的最优解由子问题最优解构成。
2. **重叠子问题**：递归过程中同一子问题被反复求解。

动态规划**用表（数组）存储子问题的解**，避免重复计算（记忆化），再自底向上或自顶向下地构造原问题的解。它是"用空间换时间"的典范。

### 与分治、贪心的区别

- 分治的子问题**互不重叠**；动态规划的子问题**大量重叠**。
- 贪心做"不可撤销"的局部选择；动态规划**综合所有子问题**做全局最优决策。

### 典型例子

1. **0-1 背包问题**：`dp[i][w]` 表示前 i 件物品在容量 w 下的最大价值。
2. **最长公共子串 / 最长公共子序列**：二维 DP 表格，`dp[i][j]` 记录以 i、j 结尾的最优值。
3. **矩阵链乘法顺序**、**最优二叉查找树**。
4. **Floyd-Warshall 所有点对最短路径**（三维循环的 DP）。
5. **编辑距离（Levenshtein）**、**爬楼梯 / 斐波那契**（最简单示例）。

### 求解框架

1. 定义状态（`dp` 数组含义）。
2. 写出**状态转移方程**。
3. 确定初始化与边界条件。
4. 确定遍历顺序与最终答案。

## 随机化算法（Randomized）

利用随机性改善算法性能或简化实现：

- **随机数发生器**：算法的基础组件。
- **快速排序随机选基准**：避免最坏 $O(n^2)$。
- **跳跃表（Skip List）**：以随机层高替代平衡树的旋转，期望 $O(\log n)$。
- **素性测试（Miller-Rabin）**：随机化概率测试，速度快于确定性方法。
- **蒙特卡洛 / 拉斯维加斯**两类随机化策略。

## 回溯算法（Backtracking）

回溯 = **深度优先搜索 + 剪枝 + 撤销**，用于枚举解空间（见"查找与搜索"一篇）。典型：N 皇后、数独、收费公路重建、博弈树（极大极小搜索）。

## 摊还分析（Amortized Analysis）

摊还分析衡量**一系列操作**的**平均**代价（而非单次最坏代价），说明"虽然某次操作可能很贵，但总体平均很便宜"。

三种方法：

1. **聚合分析（Aggregate）**：计算 n 次操作的总代价再除以 n。
2. **记账法（Accounting）**：每次操作预收"信用"，贵的操作消耗之前积累的信用。
3. **势能法（Potential）**：定义势函数刻画数据结构状态，摊还代价 = 实际代价 + 势能变化。

**应用**：动态数组扩容（`ArrayList` 追加摊还 $O(1)$）、二项队列、斜堆、斐波那契堆、伸展树。

## NP 完全性（NP-Completeness）

### 问题分类

- **P 类**：能在多项式时间内求解的问题（如排序、最短路径）。
- **NP 类**：解能在多项式时间内**验证**的问题。
- **NP 完全（NP-Complete）**：NP 中最难的一类——任何 NP 问题都可多项式归约到它。若能多项式求解一个 NP 完全问题，则 P = NP。
- **NP 难（NP-Hard）**：至少与 NP 完全一样难（未必在 NP 内）。

### 识别与应对

判断问题是否 NP 完全的经验法则：**元素较多时无法快速求解，且需要计算所有组合/序列、或涉及集合划分/覆盖**。例如：旅行商问题、集合覆盖、背包问题（0-1）、图的着色。

应对 NP 完全问题没有已知多项式算法，常用策略：

1. 求**近似解**（贪心近似、启发式）。
2. 对小规模输入**精确求解**（回溯、分支限界）。
3. 求**特例**的最优解。

## K 最近邻算法（KNN）



KNN 是一种**简单的机器学习算法**，用于**分类**与**回归**：判断一个新样本的类别时，找到与其**特征最接近的 K 个**已知样本，用多数表决（分类）或平均值（回归）决定结果。

关键要素：

- **特征提取**：把对象转换为可比较的特征向量（如水果的"大小 + 颜色"）。
- **距离度量**：欧氏距离、曼哈顿距离、余弦相似度等。
- **K 的选择**：K 过小易过拟合，过大易欠拟合。
- **应用**：推荐系统（"相似用户也喜欢"）、OCR 手写识别、垃圾邮件过滤。

## 外部排序

当数据大到无法一次载入内存时，采用**外部排序**：

1. **生成初始顺串**：分批读入内存排序后写回磁盘（可用**替换选择**生成更长的顺串）。
2. **多路归并**：同时归并多个顺串。
3. **多相合并**：优化磁盘读写分配。

## Kotlin 实现

### 动态规划：0-1 背包

```kotlin
fun knapsack(weights: IntArray, values: IntArray, capacity: Int): Int {
    val n = weights.size
    val dp = IntArray(capacity + 1) // 一维滚动数组
    for (i in 0 until n) {
        for (w in capacity downTo weights[i]) { // 逆序避免重复选同一物品
            dp[w] = maxOf(dp[w], dp[w - weights[i]] + values[i])
        }
    }
    return dp[capacity]
}
```

### 动态规划：最长公共子串

```kotlin
fun longestCommonSubstring(a: String, b: String): String {
    val m = a.length
    val n = b.length
    val dp = Array(m + 1) { IntArray(n + 1) }
    var maxLen = 0
    var end = 0
    for (i in 1..m) {
        for (j in 1..n) {
            if (a[i - 1] == b[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1] + 1
                if (dp[i][j] > maxLen) {
                    maxLen = dp[i][j]
                    end = i
                }
            }
        }
    }
    return a.substring(end - maxLen, end)
}
```

### 动态规划：最长公共子序列

```kotlin
fun longestCommonSubsequence(a: String, b: String): Int {
    val m = a.length
    val n = b.length
    val dp = Array(m + 1) { IntArray(n + 1) }
    for (i in 1..m) {
        for (j in 1..n) {
            dp[i][j] = if (a[i - 1] == b[j - 1])
                dp[i - 1][j - 1] + 1
            else
                maxOf(dp[i - 1][j], dp[i][j - 1])
        }
    }
    return dp[m][n]
}
```

### 贪心：活动选择（区间调度）

```kotlin
fun activitySelection(activities: List<Pair<Int, Int>>): Int {
    val sorted = activities.sortedBy { it.second } // 按结束时间升序
    var count = 0
    var lastEnd = Int.MIN_VALUE
    for ((start, end) in sorted) {
        if (start >= lastEnd) { // 与已选活动不冲突
            count++
            lastEnd = end
        }
    }
    return count
}
```
