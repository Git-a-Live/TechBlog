## 图的遍历

图的遍历是几乎所有图算法的**骨架**：从某个顶点出发，按规则系统地访问所有可达顶点。两种基本策略（DFS/BFS 的通用原理见"查找与搜索"篇）：

- **深度优先遍历（DFS）**：沿一条路径走到尽头再回溯，用栈（递归）实现。在图上的价值在于它能记录"发现时间/完成时间"，从而衍生出拓扑排序、强连通分量、割点判定等一系列算法。
- **广度优先遍历（BFS）**：按"距离起点"逐层扩展，用队列实现。它保证**首次**到达某顶点的层数即是最短距离，是无权图最短路径的基础。

## 拓扑排序（Topological Sort）

### 定义

拓扑排序是对**有向无环图（DAG）**的顶点的一种线性排序：若存在边 $u \to v$，则 $u$ 在排序中位于 $v$ **之前**。若图中存在环，则**不存在**拓扑排序——因此拓扑排序本身也是检测有向环的方法。

### 应用

课程先修关系、编译/构建依赖、任务调度、关键路径分析。

### 实现一：Kahn 算法（入度法）

反复选取**入度为 0** 的顶点输出，并"删除"它的所有出边（令后继顶点入度减一）。用队列维护当前入度为 0 的顶点：

```
1. 计算所有顶点的入度
2. 将所有入度为 0 的顶点入队
3. 当队列非空：
     取出队首 u，加入排序结果
     对 u 的每条出边 (u→v)：
        indegree[v] -= 1
        若 indegree[v] == 0，将 v 入队
4. 若排序结果顶点数 < V，说明图中有环
```

- 复杂度：$O(V+E)$。
- 本质是：没有"前置依赖"的任务先执行，执行完成后释放后续任务的前置条件。

### 实现二：DFS 后序法

对图做 DFS，在某个顶点**完成**（所有邻居都已访问完）时将它压入栈，最后**逆序输出**栈即可。DFS 天然保证有依赖关系的顶点先被完成、后进栈，因此逆序即拓扑序。

## 强连通分量（SCC）

### 定义

有向图中，若顶点 u、v **互相可达**，则它们属于同一个强连通分量（Strongly Connected Component）。求 SCC 的意义在于：把有向图"压缩"为**有向无环图（DAG）**——每个 SCC 收缩成一个顶点，简化了依赖分析、可达性判断等问题。

### 实现一：Kosaraju 算法

基于一个关键性质：**对原图与反图（所有边反向）分别做 DFS，两轮的结束顺序能揭示 SCC 结构**。两步：

1. 对原图做 DFS，按**完成时间**记录顶点的逆后序（后序的逆序）。
2. 按上一步得到的顺序，对**反图**做 DFS，每次能访问到的顶点集合就是一个 SCC。

- 复杂度：$O(V+E)$，两次 DFS。

### 实现二：Tarjan 算法

在一次 DFS 中，用 `dfn`（发现时间）与 `low`（能回溯到的最早祖先）数组判定 SCC：当某顶点满足 `dfn[u] == low[u]` 时，栈中它之上的顶点构成一个 SCC。复杂度同为 $O(V+E)$。

## 割点与割边（双连通性）

无向图中，去掉某个顶点（**割点/关节点**）或某条边（**割边/桥**）会使图的连通分量增加。识别割点割边是网络可靠性分析（哪些节点/链路是"单点故障"）的基础。

**Tarjan 算法思想**：在 DFS 生成树上，用 `dfn[u]`（发现时间）与 `low[u]`（u 不经过父边能到达的最小 dfn）判定：

- 根顶点若有**多个**孩子，则是割点；非根顶点 u 若存在孩子 v 满足 `low[v] >= dfn[u]`，则 u 是割点。
- 边 (u, v) 若满足 `low[v] > dfn[u]`，则是割边（桥）。

- 复杂度：$O(V+E)$。

## 欧拉回路（简述）

欧拉回路是**恰好经过每条边一次**并回到起点的回路；欧拉路径则不必回到起点。判定（连通前提下）：

- 无向图：存在欧拉回路当且仅当**所有顶点度数为偶**；存在欧拉路径当且仅当**恰有两个奇度顶点**（作为起终点）。
- 有向图：每个顶点入度等于出度（回路）。

> 这是经典的"一笔画"问题，用 Hierholzer 算法在 $O(E)$ 内构造解。

## Kotlin 实现

### 拓扑排序（Kahn 入度法）

```kotlin
fun topologicalSort(n: Int, edges: List<Pair<Int, Int>>): List<Int> {
    val indegree = IntArray(n)
    val graph = Array(n) { mutableListOf<Int>() }
    for ((u, v) in edges) {
        graph[u].add(v)
        indegree[v]++
    }
    val queue = ArrayDeque<Int>()
    for (i in 0 until n) if (indegree[i] == 0) queue.add(i)
    val order = mutableListOf<Int>()
    while (queue.isNotEmpty()) {
        val u = queue.removeFirst()
        order.add(u)
        for (v in graph[u]) {
            if (--indegree[v] == 0) queue.add(v)
        }
    }
    // 若 order.size < n，说明图中有环，不存在拓扑序
    return if (order.size == n) order else emptyList()
}
```

### 强连通分量（Kosaraju，两次 DFS）

```kotlin
fun kosaraju(n: Int, edges: List<Pair<Int, Int>>): List<List<Int>> {
    val graph = Array(n) { mutableListOf<Int>() }
    val rev = Array(n) { mutableListOf<Int>() } // 反图
    for ((u, v) in edges) {
        graph[u].add(v)
        rev[v].add(u)
    }
    // 第一遍 DFS：按完成时间记录顺序
    val visited = BooleanArray(n)
    val order = mutableListOf<Int>()
    fun dfs1(u: Int) {
        visited[u] = true
        for (v in graph[u]) if (!visited[v]) dfs1(v)
        order.add(u)
    }
    for (i in 0 until n) if (!visited[i]) dfs1(i)

    // 第二遍 DFS：在反图上按逆序遍历，得到强连通分量
    visited.fill(false)
    val result = mutableListOf<List<Int>>()
    fun dfs2(u: Int, comp: MutableList<Int>) {
        visited[u] = true
        comp.add(u)
        for (v in rev[u]) if (!visited[v]) dfs2(v, comp)
    }
    for (u in order.asReversed()) {
        if (!visited[u]) {
            val comp = mutableListOf<Int>()
            dfs2(u, comp)
            result.add(comp)
        }
    }
    return result
}
```
