查找（Search）与搜索（遍历）是算法最基础也最广泛的问题：在数据集合中定位目标元素，或在状态空间中寻找从起点到目标的路径。本章涵盖线性查找、二分查找、枚举（暴力搜索）、深度优先搜索、广度优先搜索与回溯。

## 线性查找（顺序查找）

**思想**：从第一个元素开始，逐个与目标值比较，直到找到或遍历结束。无需任何预处理，也不要求数据有序。

- 时间复杂度：最坏 $O(n)$，平均 $O(n)$。
- 空间复杂度：$O(1)$。
- 适用场景：无序、小规模数据，或只需查找一次的场景。

## 二分查找（Binary Search）

### 核心思想

二分查找是一种**高效的查找算法，其输入必须是"有序"的元素列表**。它每次取区间的中间元素与目标比较：

- 若相等，返回位置；
- 若中间元素**大于**目标，说明目标只可能在左半区间，丢弃右半区；
- 若中间元素**小于**目标，说明目标只可能在右半区间，丢弃左半区。

每一次比较都能**排除一半**的候选元素，因此时间复杂度为 $O(\log n)$。

> 示例：在 1~100 之间猜数字，每次猜中间值，最多 7 次即可猜中（$\log_2 100 \approx 6.64$）；而在 240000 个单词的字典里查一个词，二分查找最多约 18 步（$\log_2 240000 \approx 17.9$），而线性查找最坏需要 240000 步。

### 实现

```kotlin
fun binarySearch(a: IntArray, target: Int): Int {
    var low = 0
    var high = a.size - 1
    while (low <= high) {
        val mid = low + (high - low) / 2 // 用减法避免 (low+high) 溢出
        when {
            a[mid] == target -> return mid
            a[mid] > target -> high = mid - 1
            else -> low = mid + 1
        }
    }
    return -1 // 未找到
}
```

Kotlin 标准库内建二分查找，要求集合有序，返回元素下标，未找到时返回负值（`-插入点-1`）：

```kotlin
val arr = intArrayOf(1, 3, 5, 7, 9)
val idx = arr.binarySearch(5)             // 2，找到返回下标
val miss = arr.binarySearch(6)            // -4，未找到返回负值

val list = listOf(1, 3, 5, 7, 9)
list.binarySearch(7)                      // 3
list.binarySearch(7, 0, list.size)        // 指定范围查找
```

### 注意点

1. **边界条件**：循环条件是 `low <= high`（而非 `<`），否则会漏判 `low == high` 的元素。
2. **中点计算**：用 `low + (high - low) / 2` 而非 `(low + high) / 2`，避免整数溢出。
3. **区间收缩**：`high = mid - 1` 与 `low = mid + 1`，必须排除已检查的 mid，否则可能死循环。
4. **前提**：仅当列表**有序**时二分查找才有效。

### 常见变体

- **查找第一个等于目标的位置** / **最后一个等于目标的位置**（处理重复元素）。
- **查找第一个大于等于目标的位置（lower_bound）**。
- **在"先增后减"或旋转有序数组中的二分**（变体，边界判断更复杂）。

## 枚举（暴力搜索）

**思想**：穷举问题解空间中的**所有可能**，逐一判断是否满足条件。枚举是"最暴力"也最通用的方法，思路简单、不易出错，但当解空间巨大时不可行。

**示例**：

- **数的全排列**：用嵌套循环或递归枚举 n 个数的所有排列。
- **火柴棍等式**：枚举所有数字组合，验证是否满足等式并检查火柴棍总数。
- **炸弹人**：枚举所有可放置位置，计算每个位置能消灭的敌人数量，取最大值。

> 枚举的要点是**控制解空间规模**：通过剪枝（提前排除不可能的分支）和数学推导缩小搜索范围，避免无谓的计算。

## 深度优先搜索（DFS）

### 核心思想

深度优先搜索是"**不撞南墙不回头**"的搜索策略：沿着一条路径尽可能深入，走到尽头再**回溯**到最近的分叉点，尝试另一条路径，直到找到目标或遍历完所有节点。

### 实现方式

DFS 通常用**递归**实现（递归天然利用调用栈保存回溯点），也可用显式栈改写为迭代形式。

```
DFS(当前节点):
    若当前节点是目标 → 返回成功
    标记当前节点为已访问
    对当前节点的每个未访问邻居:
        DFS(邻居)
    若所有分支都失败 → 回溯
```

### 典型应用

1. **数的全排列**：逐个位置选择数字，递归深入。
2. **迷宫寻路**（"解救小哈"）：从起点沿一个方向走到死路再回退，直到找到出口。
3. **图的连通性**：遍历连通分量、判断可达性。
4. **拓扑排序的递归实现**、**求强连通分量**。

### 特点

- 时间复杂度：$O(V+E)$（图），$O(\text{状态数})$（状态空间）。
- 空间复杂度：$O(h)$，h 为递归深度（**与深度成正比**）。
- 优点：能"探到底"，适合需要遍历全部解、判断连通性、求路径存在性的场景。
- 缺点：递归深度过大时可能栈溢出；**不保证找到最短路径**。

## 广度优先搜索（BFS）

### 核心思想

广度优先搜索是"**层层递进**"的搜索策略：从起点出发，先访问距离为 1 的所有节点，再访问距离为 2 的所有节点，依此类推。BFS 使用**队列**维护待访问节点。

### 实现方式

```
BFS(起点):
    将起点入队，标记已访问
    当队列非空:
        取出队首节点 u
        若 u 是目标 → 返回
        对 u 的每个未访问邻居 v:
            标记 v 已访问，将 v 入队
```

### 典型应用

1. **无权图的最短路径**：BFS 按层扩展，**首次**到达某节点时走过的步数即是最短距离。这是广度优先搜索的核心结论。
2. **迷宫最少步数**（"宝岛探险""水管工游戏"）。
3. **社交网络中的最短关系链**（如两个用户之间的好友距离）。
4. **层次遍历二叉树**。

### 特点

- 时间复杂度：$O(V+E)$。
- 空间复杂度：$O(w)$，w 为队列中同层节点数（**与宽度成正比**，可能很大）。
- 优点：**保证找到无权图中的最短路径**。
- 缺点：队列可能占用大量内存（尤其宽度很大的图）。

## DFS vs BFS 对比

| 维度 | DFS | BFS |
|:---|:---|:---|
| 数据结构 | 栈（递归或显式） | 队列 |
| 遍历顺序 | 一条路走到黑 | 层层递进 |
| 空间复杂度 | $O(h)$，与深度相关 | $O(w)$，与宽度相关 |
| 最短路径 | 不能保证 | **能保证（无权图）** |
| 适用场景 | 遍历全部解、连通性、回溯 | 求最短路径、层次遍历 |
| 风险 | 深度过大栈溢出 | 宽度过大内存溢出 |

## 回溯（Backtracking）

### 核心思想

回溯是 DFS 的一种**系统化应用**：在解空间树中深度优先地试探，每走一步判断当前部分解是否仍有可能通向有效解（**可行性剪枝**），若不满足则**撤销上一步选择并回溯**，尝试其他分支。回溯 = 深度优先 + 剪枝 + 撤销。

### 典型应用

1. **N 皇后问题**：逐行放置皇后，若某列/对角线冲突则回溯。
2. **全排列 / 组合 / 子集**：递归枚举，通过 visited 标记或交换实现。
3. **数独求解**：对每个空格尝试 1~9，冲突则回溯。
4. **收费公路重建问题**、**博弈（极大极小）**。

### 模板

```
backtrack(路径, 选择列表):
    若满足结束条件 → 记录结果，返回
    对选择列表中的每个选择:
        做出选择
        backtrack(路径, 新的选择列表)  // 递归
        撤销选择  // 回溯的关键
```

## Kotlin 实现

### 枚举（暴力搜索）

枚举直接用嵌套循环穷举解空间：

```kotlin
// 求所有满足 a+b=c 且 a、b、c ∈ [1,9] 互不相同的三元组
val result = mutableListOf<Triple<Int, Int, Int>>()
for (a in 1..9) {
    for (b in 1..9) {
        for (c in 1..9) {
            if (a != b && b != c && a != c && a + b == c) {
                result.add(Triple(a, b, c))
            }
        }
    }
}
```

### 深度优先搜索（DFS）

```kotlin
// 图的邻接表 DFS 遍历
fun dfs(graph: Map<Int, List<Int>>, start: Int) {
    val visited = mutableSetOf<Int>()
    fun visit(u: Int) {
        visited.add(u)
        println(u)
        for (v in graph[u].orEmpty()) {
            if (v !in visited) visit(v) // 递归深入
        }
    }
    visit(start)
}
```

### 广度优先搜索（BFS）

```kotlin
// 无权图的 BFS，返回起点到各顶点的最短距离
fun bfs(graph: Map<Int, List<Int>>, start: Int): Map<Int, Int> {
    val dist = mutableMapOf(start to 0) // 距离表，同时充当 visited
    val queue = ArrayDeque<Int>()
    queue.add(start)
    while (queue.isNotEmpty()) {
        val u = queue.removeFirst()
        for (v in graph[u].orEmpty()) {
            if (v !in dist) {
                dist[v] = dist.getValue(u) + 1 // 首次到达即最短距离
                queue.add(v)
            }
        }
    }
    return dist
}
```

### 回溯（以全排列、N 皇后为例）

```kotlin
// 全排列：枚举所有排列
fun permute(nums: IntArray): List<List<Int>> {
    val res = mutableListOf<List<Int>>()
    val used = BooleanArray(nums.size)
    fun backtrack(path: MutableList<Int>) {
        if (path.size == nums.size) {
            res.add(path.toList()) // 记录一个完整排列
            return
        }
        for (i in nums.indices) {
            if (used[i]) continue
            used[i] = true
            path.add(nums[i])                    // 做出选择
            backtrack(path)                      // 递归深入
            path.removeAt(path.size - 1)         // 撤销选择（回溯）
            used[i] = false
        }
    }
    backtrack(mutableListOf())
    return res
}

// N 皇后：用三个布尔数组记录列与两条对角线占用，冲突即剪枝回溯
fun solveNQueens(n: Int): List<List<String>> {
    val res = mutableListOf<List<String>>()
    val board = Array(n) { CharArray(n) { '.' } }
    val cols = BooleanArray(n)
    val diag1 = BooleanArray(2 * n) // 主对角线（row - col + n）
    val diag2 = BooleanArray(2 * n) // 副对角线（row + col）

    fun backtrack(row: Int) {
        if (row == n) {
            res.add(board.map { String(it) })
            return
        }
        for (col in 0 until n) {
            if (cols[col] || diag1[row - col + n] || diag2[row + col]) continue
            cols[col] = true; diag1[row - col + n] = true; diag2[row + col] = true
            board[row][col] = 'Q'
            backtrack(row + 1)
            board[row][col] = '.'
            cols[col] = false; diag1[row - col + n] = false; diag2[row + col] = false
        }
    }
    backtrack(0)
    return res
}
```
