排序是算法领域研究最透彻的问题之一：将一组元素按主键（key）的大小（升序或降序）重新排列。排序是二分查找等高效算法的**前置条件**，也是众多实际问题（去重、统计、Top-K）的基础。

## 基本概念

- **原地排序**：除递归栈和少量变量外，不需要额外内存的排序（如选择、插入、希尔、快速、堆排序）。
- **稳定性**：若两个相等主键的元素在排序前后相对顺序不变，则算法是**稳定**的。稳定性对多关键字排序（如先按成绩、再按姓名）至关重要。
- **内部排序 / 外部排序**：数据能否全部载入内存。数据量大到无法一次载入时，用外部排序（多路归并）。
- **比较排序 / 非比较排序**：比较排序通过比较元素大小排序；非比较排序（桶、计数、基数）利用元素取值特点，可突破比较排序的 $O(n \log n)$ 下界。

## 非比较排序

### 桶排序（Bucket Sort）

**思想**（"最快最简单的排序"）：准备一组"桶"（通常是按值域划分的计数数组），将每个元素放入对应编号的桶，最后按桶顺序依次取出。

- 以"统计成绩分布"为例：用 `book[101]` 计数 0~100 分的人数，每个分数是天然有序的"桶"。
- 时间复杂度：$O(n + k)$，k 为桶的数量（值域大小）。
- 空间复杂度：$O(k)$。
- 适用条件：**值域有限且较小**。值域过大时桶会过多、浪费空间。

### 计数排序（Counting Sort）

桶排序的特例：先统计每个取值出现的次数，再通过**前缀和**确定每个元素在输出数组中的位置，是稳定的线性排序。时间复杂度 $O(n+k)$，空间 $O(k)$。

### 基数排序（Radix Sort）

**思想**：从最低有效位（LSD）到最高有效位（MSD），逐位进行稳定的桶/计数排序。每一趟按当前位排序，稳定排序保证了高位排序时低位次序不被打乱。

- 时间复杂度：$O(d \cdot (n+k))$，d 为最大位数，k 为基数（如 10）。
- 空间复杂度：$O(n+k)$。
- 适用于**定长整数、字符串**等可逐位拆分的键。

## 比较排序

### 冒泡排序（Bubble Sort）

**思想**：反复比较相邻元素，逆序则交换，使较大元素像气泡一样逐步"浮"到数组末尾。

- 每趟排序确定一个最大元素到正确位置，最多 n-1 趟。
- 时间复杂度：最坏/平均 $O(n^2)$，最好（已有序）$O(n)$。
- 空间复杂度：$O(1)$，稳定，原地。
- 特点：实现简单，可提前终止（某趟无交换则已有序），但性能差，仅用于教学或小数据量。

### 选择排序（Selection Sort）

**思想**：每一趟在未排序区间中**选出最小元素**，放到已排序区间的末尾（与未排序区间第一个元素交换）。

- 时间复杂度：**所有情况都是 $O(n^2)$**（比较次数固定为 $\frac{n(n-1)}{2}$），交换次数为 $O(n)$。
- 空间复杂度：$O(1)$，原地。通常实现**不稳定**。
- 特点：交换次数少（每趟至多一次），当元素"移动"代价远大于"比较"代价时有优势。

### 插入排序（Insertion Sort）

**思想**：将数组分为"已排序"与"未排序"两部分，每次取未排序区间的第一个元素，在已排序区间中从后向前找到正确位置**插入**。

- 时间复杂度：最坏/平均 $O(n^2)$，最好（已有序）$O(n)$。
- 空间复杂度：$O(1)$，**稳定**，原地。
- 特点：对**接近有序**的输入非常快（接近 $O(n)$）；对小规模数组（如 n < 10）是快速排序、归并排序常用的优化手段。

### 希尔排序（Shell Sort）

**思想**：插入排序的改进。先以较大的**增量（gap）**分组进行插入排序，使元素"基本有序"，再逐步缩小增量，最后 gap=1 时完成整体插入排序。基本有序的数组对插入排序是高效的。

- 时间复杂度：依赖增量序列，约 $O(n^{1.3})$（Hibbard 序列）到 $O(n \log^2 n)$，最坏仍可到 $O(n^2)$。
- 空间复杂度：$O(1)$，原地，**不稳定**。
- 特点：突破"相邻交换"的限制，是初级排序中性能最好的，但实现易出错。

### 归并排序（Merge Sort）

**思想**（分治）：将数组**递归地**对半拆分为两个子数组，分别排序，再**合并（merge）**两个有序子数组。合并时用双指针依次比较取较小者。

- 时间复杂度：**稳定地 $O(n \log n)$**（所有情况一致）。
- 空间复杂度：$O(n)$（需要临时数组存储合并结果）。
- **稳定**，但非原地。
- 特点：性能稳定、可预测；是外部排序（多路归并）的核心；缺点是额外内存开销。链表归并排序可做到原地。

### 快速排序（Quick Sort）

**思想**（分治）：选取一个**基准（pivot）**，将数组划分为"小于基准"和"大于基准"两部分，再对两部分递归排序。划分完成后基准就位于最终位置。

- 时间复杂度：**平均 $O(n \log n)$**，最坏（如已有序且选端点为基准）$O(n^2)$。
- 空间复杂度：$O(\log n)$（递归栈深度，原地划分）。
- **不稳定**，原地。
- 特点：平均情况下常数因子小，实践中常**优于归并排序**；通过随机选基准、三数取中等策略可避免最坏情况；对小数组常切换为插入排序。

> **快速排序与归并排序**：归并排序是"先分后合"，合并阶段工作量最大；快速排序是"先划分后排"，划分阶段（选基准、分区）工作量最大。两者都是分治的经典体现，平均复杂度同为 $O(n \log n)$。

### 堆排序（Heap Sort）

**思想**：利用**二叉堆**（最大堆）的性质。先将数组建成最大堆，然后反复"取出堆顶（最大元素）与堆尾交换、缩小堆规模、下沉调整"，最终得到升序数组。

- 时间复杂度：$O(n \log n)$（建堆 $O(n)$，n 次下沉）。
- 空间复杂度：$O(1)$，**原地**（这是它相对归并排序的优势）。
- **不稳定**。
- 特点：原地且最坏 $O(n \log n)$，综合表现优秀；但常数因子通常大于快速排序，且缓存不友好。

## 排序算法的一般下界

对于**基于比较**的排序算法，其最坏情况下的比较次数存在下界：

$$\text{比较次数} \geq \log_2(n!) \approx n \log_2 n$$

**证明思路**（决策树模型）：n 个元素的排序结果有 $n!$ 种可能排列，每次比较最多把结果分成两类，因此需要至少一棵高度为 $\log_2(n!)$ 的决策树。由斯特林公式 $n! \approx \sqrt{2\pi n}(\frac{n}{e})^n$，得 $\log_2(n!) = \Omega(n \log n)$。

> 结论：任何比较排序算法在**最坏情况下都不可能优于 $O(n \log n)$**。归并排序、堆排序达到了这一下界；快速排序平均达到。要突破它，必须使用非比较排序（桶/计数/基数），它们利用了键值的额外信息。

## 排序算法总览

| 算法 | 平均时间 | 最坏时间 | 最好时间 | 空间 | 稳定性 | 原地 |
|:---|:---|:---|:---|:---|:---|:---|
| 冒泡排序 | $O(n^2)$ | $O(n^2)$ | $O(n)$ | $O(1)$ | 稳定 | 是 |
| 选择排序 | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 不稳定 | 是 |
| 插入排序 | $O(n^2)$ | $O(n^2)$ | $O(n)$ | $O(1)$ | 稳定 | 是 |
| 希尔排序 | $O(n^{1.3})$ | $O(n^2)$ | $O(n)$ | $O(1)$ | 不稳定 | 是 |
| 归并排序 | $O(n \log n)$ | $O(n \log n)$ | $O(n \log n)$ | $O(n)$ | 稳定 | 否 |
| 快速排序 | $O(n \log n)$ | $O(n^2)$ | $O(n \log n)$ | $O(\log n)$ | 不稳定 | 是 |
| 堆排序 | $O(n \log n)$ | $O(n \log n)$ | $O(n \log n)$ | $O(1)$ | 不稳定 | 是 |
| 计数排序 | $O(n+k)$ | $O(n+k)$ | $O(n+k)$ | $O(k)$ | 稳定 | 否 |
| 桶排序 | $O(n+k)$ | $O(n^2)$ | $O(n+k)$ | $O(n+k)$ | 稳定 | 否 |
| 基数排序 | $O(d(n+k))$ | $O(d(n+k))$ | $O(d(n+k))$ | $O(n+k)$ | 稳定 | 否 |

## 算法选型

1. **规模小**（n < 几十）：插入排序或选择排序即可，简单且常数小。
2. **接近有序**：插入排序、冒泡排序（可提前终止）。
3. **需要稳定性**：归并排序、插入排序、冒泡排序、计数/桶/基数排序。
4. **空间受限、要求原地**：堆排序（最坏 $O(n\log n)$ 且原地）、快速排序（平均最优）。
5. **要求最坏 $O(n\log n)$ 且稳定**：归并排序。
6. **键值为有限整数/可逐位拆分**：计数排序、基数排序、桶排序。
7. **数据无法一次载入内存**：外部排序（多路归并、多相合并、替换选择）。

## Kotlin 实现

### Kotlin 内建排序方法

Kotlin 标准库提供完善的排序 API，覆盖大多数常见排序需求：

| 方法 | 作用 | 说明 |
|:---|:---|:---|
| `IntArray.sort()` / `MutableList.sort()` | 原地升序排序 | 要求元素可比较 |
| `sortDescending()` | 原地降序排序 | |
| `sorted()` | 返回升序**新集合** | 不修改原集合 |
| `sortedDescending()` | 返回降序新集合 | |
| `sortedBy { it.field }` | 按指定字段升序 | 常用 |
| `sortedWith(compareBy { ... })` | 多关键字排序 | 先按前一个条件，再按后一个 |

```kotlin
val nums = intArrayOf(5, 2, 8, 1, 9)
nums.sort()                        // 原地升序：[1, 2, 5, 8, 9]

val list = listOf(5, 2, 8, 1, 9)
val asc = list.sorted()            // 升序新列表，原 list 不变
val desc = list.sortedDescending() // 降序

data class User(val name: String, val age: Int)
val users = listOf(User("a", 20), User("b", 18), User("c", 18))
users.sortedBy { it.age }                          // 按 age 升序
users.sortedWith(compareBy({ it.age }, { it.name })) // 先 age 升序、再 name 升序
```

> Kotlin 内建排序的底层实现：对象集合（`List`/`Array<对象>`）使用 **TimSort**（归并 + 插入的混合，**稳定**）；基本类型数组（`IntArray` 等）使用**双轴快速排序**。算法思想与本篇一致，只是工程实现做了大量优化。

### 手写实现

> 以下实现用于说明算法原理，工程开发中可直接使用上述内建方法。

#### 冒泡排序

```kotlin
fun bubbleSort(a: IntArray) {
    for (i in a.indices) {
        var swapped = false
        for (j in 0 until a.size - 1 - i) {
            if (a[j] > a[j + 1]) {
                val t = a[j]; a[j] = a[j + 1]; a[j + 1] = t
                swapped = true
            }
        }
        if (!swapped) break // 某趟无交换，已有序，提前终止
    }
}
```

#### 选择排序

```kotlin
fun selectionSort(a: IntArray) {
    for (i in a.indices) {
        var minIdx = i
        for (j in i + 1 until a.size) {
            if (a[j] < a[minIdx]) minIdx = j
        }
        val t = a[i]; a[i] = a[minIdx]; a[minIdx] = t
    }
}
```

#### 插入排序

```kotlin
fun insertionSort(a: IntArray) {
    for (i in 1 until a.size) {
        val key = a[i]
        var j = i - 1
        while (j >= 0 && a[j] > key) {
            a[j + 1] = a[j] // 右移腾位
            j--
        }
        a[j + 1] = key
    }
}
```

#### 希尔排序

```kotlin
fun shellSort(a: IntArray) {
    var gap = a.size / 2
    while (gap > 0) {
        for (i in gap until a.size) {
            val key = a[i]
            var j = i
            while (j >= gap && a[j - gap] > key) {
                a[j] = a[j - gap]
                j -= gap
            }
            a[j] = key
        }
        gap /= 2 // 缩小增量
    }
}
```

#### 归并排序

```kotlin
fun mergeSort(a: IntArray, lo: Int = 0, hi: Int = a.size - 1) {
    if (lo >= hi) return
    val mid = (lo + hi) / 2
    mergeSort(a, lo, mid)
    mergeSort(a, mid + 1, hi)
    merge(a, lo, mid, hi)
}

private fun merge(a: IntArray, lo: Int, mid: Int, hi: Int) {
    val tmp = IntArray(hi - lo + 1)
    var i = lo; var j = mid + 1; var k = 0
    while (i <= mid && j <= hi) {
        tmp[k++] = if (a[i] <= a[j]) a[i++] else a[j++] // 等号保证稳定
    }
    while (i <= mid) tmp[k++] = a[i++]
    while (j <= hi) tmp[k++] = a[j++]
    for (t in tmp.indices) a[lo + t] = tmp[t]
}
```

#### 快速排序

```kotlin
fun quickSort(a: IntArray, lo: Int = 0, hi: Int = a.size - 1) {
    if (lo >= hi) return
    val p = partition(a, lo, hi)
    quickSort(a, lo, p - 1)
    quickSort(a, p + 1, hi)
}

private fun partition(a: IntArray, lo: Int, hi: Int): Int {
    val pivot = a[hi] // 以区间末尾元素为基准
    var i = lo
    for (j in lo until hi) {
        if (a[j] < pivot) {
            val t = a[i]; a[i] = a[j]; a[j] = t
            i++
        }
    }
    val t = a[i]; a[i] = a[hi]; a[hi] = t
    return i // 基准最终位置
}
```

#### 堆排序

```kotlin
fun heapSort(a: IntArray) {
    // 建最大堆：从最后一个非叶节点开始下沉
    for (i in a.size / 2 - 1 downTo 0) siftDown(a, i, a.size)
    for (end in a.size - 1 downTo 1) {
        val t = a[0]; a[0] = a[end]; a[end] = t // 堆顶与堆尾交换
        siftDown(a, 0, end)
    }
}

private fun siftDown(a: IntArray, i: Int, size: Int) {
    var parent = i
    while (true) {
        val left = 2 * parent + 1
        val right = 2 * parent + 2
        var largest = parent
        if (left < size && a[left] > a[largest]) largest = left
        if (right < size && a[right] > a[largest]) largest = right
        if (largest == parent) return
        val t = a[parent]; a[parent] = a[largest]; a[largest] = t
        parent = largest
    }
}
```

#### 计数排序

```kotlin
fun countingSort(a: IntArray, maxVal: Int): IntArray {
    val count = IntArray(maxVal + 1)
    for (x in a) count[x]++
    val out = IntArray(a.size)
    var k = 0
    for (v in count.indices) repeat(count[v]) { out[k++] = v }
    return out
}
```

#### 桶排序（值域为有限整数）

```kotlin
fun bucketSort(a: IntArray, maxVal: Int): IntArray {
    val buckets = IntArray(maxVal + 1) // 桶 = 按值计数的数组
    for (x in a) buckets[x]++
    val out = IntArray(a.size)
    var k = 0
    for (v in buckets.indices) repeat(buckets[v]) { out[k++] = v }
    return out
}
```

> 桶排序与计数排序在"值域为有限整数"时本质相同。更一般化的桶排序是"每个桶内再各自排序"，上面的实现是其最简的计数形式。

#### 基数排序（LSD，逐位稳定计数排序）

```kotlin
fun radixSort(a: IntArray): IntArray {
    var arr = a
    var exp = 1
    val max = arr.maxOrNull() ?: return arr
    while (max / exp > 0) {
        arr = countingSortByDigit(arr, exp)
        exp *= 10
    }
    return arr
}

private fun countingSortByDigit(a: IntArray, exp: Int): IntArray {
    val count = IntArray(10)
    for (x in a) count[(x / exp) % 10]++
    for (i in 1 until 10) count[i] += count[i - 1] // 前缀和定位
    val out = IntArray(a.size)
    for (i in a.indices.reversed()) { // 逆序保证稳定性
        val d = (a[i] / exp) % 10
        out[--count[d]] = a[i]
    }
    return out
}
```
