最短路径与最小生成树是图论中最经典、应用最广的两类问题。最短路径求两点间代价最小的路径；最小生成树求连接所有顶点、总代价最小的树。

## 最短路径问题

### 问题分类

| 类型 | 含义 | 代表算法 |
|:---|:---|:---|
| 单源、无权 | 一个起点到所有点的最少边数 | BFS |
| 单源、非负权 | 一个起点到所有点的最小权值和 | Dijkstra |
| 单源、可负权 | 允许负权边，可检测负环 | Bellman-Ford |
| 所有点对 | 任意两点间的最短路径 | Floyd-Warshall |

### 无权最短路径：BFS

在**无权图**（或所有边权为 1）中，BFS 按层扩展，**首次**到达某顶点的层数就是最短距离（详见"查找与搜索"一章）。复杂度 $O(V+E)$。

### Dijkstra 算法（非负权单源最短路径）

**思想**（贪心 + 松弛）：维护每个顶点到起点的当前最短距离 `dist[]`。每次从**未确定**的顶点中取出 `dist` 最小的顶点 u，确定其最短距离，并对 u 的所有邻居 v 执行**松弛（relaxation）**：

```
若 dist[v] > dist[u] + w(u,v):
    dist[v] = dist[u] + w(u,v)   // 更新更短路径
```

**关键性质**：一旦某个顶点被"确定"，其距离不再改变。这**要求所有边权非负**——这也是 Dijkstra 不适用于负权图的根本原因。

**复杂度**：用**优先队列（二叉堆）**维护"距离最小的未确定顶点"，$O((V+E)\log V)$。

Dijkstra 不能处理负权边：负权边可能使"已确定"的顶点距离被进一步缩短，破坏贪心前提。含负权边的场景需使用 Bellman-Ford。

### Bellman-Ford 算法（可负权单源最短路径）

**思想**：对**所有边**反复执行松弛，最多进行 **V-1 轮**（一条最短路径最多含 V-1 条边）。V-1 轮后若还能继续松弛，说明图中存在**负权环**（最短路径无定义）。

```
初始化 dist[起点]=0，其余为无穷大
重复 V-1 轮:
    对每条边 (u,v):
        松弛 dist[v] = min(dist[v], dist[u] + w(u,v))
再检查一轮，若还能松弛 → 存在负权环
```

- 时间复杂度：$O(VE)$。
- 队列优化（SPFA）：用队列只处理距离被更新的顶点，平均更快，但最坏仍 $O(VE)$。

### Floyd-Warshall 算法（所有点对最短路径）

**思想**（动态规划，"只有五行的算法"）：引入中间顶点集合逐步扩展，核心递推：

```
for k in 1..n:
    for i in 1..n:
        for j in 1..n:
            dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
```

`dist[i][j]` 表示"只允许经过顶点 1..k 时，i 到 j 的最短距离"。三层循环后得到任意两点最短路径。

- 时间复杂度：$O(V^3)$，空间 $O(V^2)$。
- 可处理负权边，**不能处理负权环**。
- 适合**稠密图**或需要一次性得到所有点对距离的场景。

## 最小生成树（MST）

**定义**：连通加权无向图的**最小生成树**是连接所有顶点、总权值最小的一棵无环子图（含 V-1 条边）。

### Prim 算法

**思想**（贪心，从顶点出发）：从一个起点开始，每次从"已连接顶点集合"伸出的所有边中，选择**权值最小**的一条，把新顶点纳入集合，直到覆盖所有顶点。

- 与 Dijkstra 结构相似（都用优先队列），区别在于 Prim 优先选择**最小边权**，Dijkstra 优先选择**最小累计距离**。
- 复杂度：$O((V+E)\log V)$（二叉堆）。

### Kruskal 算法

**思想**（贪心，从边出发）：将所有边按权值**从小到大排序**，依次尝试加入 MST，若该边连接的两个顶点**尚未连通**（不形成环）则加入，否则跳过。

- 用**并查集**判断是否成环（详见"并查集"一章）。
- 复杂度：$O(E \log E)$（主要取决于排序）。

### Prim vs Kruskal

| 维度 | Prim | Kruskal |
|:---|:---|:---|
| 出发点 | 顶点（逐步扩展一棵树） | 边（排序后逐条合并） |
| 依赖结构 | 优先队列 | 并查集 |
| 适用 | 稠密图 | 稀疏图 |
| 复杂度 | $O((V+E)\log V)$ | $O(E\log E)$ |

## 网络流（最大流问题）

**问题**：在有向加权图中，求从**源点 s** 到**汇点 t** 的最大流量，每条边有容量限制。

**Ford-Fulkerson 方法**：不断寻找**增广路径**（还有剩余容量的路径）并增加流量，直到不存在增广路径。经典算法：

- **Edmonds-Karp**：用 BFS 找增广路径，$O(VE^2)$。
- **Dinic**：分层图 + 阻塞流，更高效。

**最大流最小割定理**：最大流的值等于最小割的容量。

## 二分图最大匹配

**二分图**：顶点可划分为两个集合，所有边都横跨两个集合。**匹配**是一组两两不共享顶点的边。

**匈牙利算法（Hungarian Algorithm）**：通过"增广路"不断改进匹配，求得最大匹配，复杂度 $O(VE)$。以"月老牵线"（相亲配对）为例。

## Kotlin 实现

### Dijkstra（优先队列 + 松弛）

```kotlin
fun dijkstra(n: Int, edges: List<Triple<Int, Int, Int>>, start: Int): IntArray {
    val graph = Array(n) { mutableListOf<Pair<Int, Int>>() } // (邻居, 权值)
    for ((u, v, w) in edges) graph[u].add(v to w)
    val dist = IntArray(n) { Int.MAX_VALUE }
    dist[start] = 0
    val pq = PriorityQueue<Pair<Int, Int>>(compareBy { it.second }) // (顶点, 距离)
    pq.add(start to 0)
    val done = BooleanArray(n)
    while (pq.isNotEmpty()) {
        val (u, d) = pq.poll()
        if (done[u]) continue
        done[u] = true
        for ((v, w) in graph[u]) {
            if (!done[v] && d + w < dist[v]) {
                dist[v] = d + w // 松弛
                pq.add(v to dist[v])
            }
        }
    }
    return dist
}
```

### Bellman-Ford（可负权，检测负环）

```kotlin
fun bellmanFord(n: Int, edges: List<Triple<Int, Int, Int>>, start: Int): IntArray? {
    val dist = IntArray(n) { Int.MAX_VALUE }
    dist[start] = 0
    repeat(n - 1) { // 最多松弛 n-1 轮
        var updated = false
        for ((u, v, w) in edges) {
            if (dist[u] != Int.MAX_VALUE && dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w
                updated = true
            }
        }
        if (!updated) break // 提前收敛
    }
    // 第 n 轮仍可松弛，说明存在负权环
    for ((u, v, w) in edges) {
        if (dist[u] != Int.MAX_VALUE && dist[u] + w < dist[v]) return null
    }
    return dist
}
```

### Floyd-Warshall（所有点对）

```kotlin
fun floydWarshall(n: Int, edges: List<Triple<Int, Int, Int>>): Array<IntArray> {
    val INF = Int.MAX_VALUE / 2
    val dist = Array(n) { IntArray(n) { INF } }
    for (i in 0 until n) dist[i][i] = 0
    for ((u, v, w) in edges) dist[u][v] = minOf(dist[u][v], w)
    for (k in 0 until n)
        for (i in 0 until n)
            for (j in 0 until n)
                dist[i][j] = minOf(dist[i][j], dist[i][k] + dist[k][j])
    return dist
}
```

### Prim（最小生成树）

```kotlin
fun prim(n: Int, edges: List<Triple<Int, Int, Int>>): Int {
    val graph = Array(n) { mutableListOf<Pair<Int, Int>>() }
    for ((u, v, w) in edges) {
        graph[u].add(v to w)
        graph[v].add(u to w) // 无向图
    }
    val inTree = BooleanArray(n)
    val minEdge = IntArray(n) { Int.MAX_VALUE } // 到已选集合的最小边权
    minEdge[0] = 0
    val pq = PriorityQueue<Pair<Int, Int>>(compareBy { it.second })
    pq.add(0 to 0)
    var total = 0
    var count = 0
    while (pq.isNotEmpty() && count < n) {
        val (u, w) = pq.poll()
        if (inTree[u]) continue
        inTree[u] = true
        total += w
        count++
        for ((v, wuv) in graph[u]) {
            if (!inTree[v] && wuv < minEdge[v]) {
                minEdge[v] = wuv
                pq.add(v to wuv)
            }
        }
    }
    return total
}
```

### Kruskal（并查集 + 边排序）

```kotlin
class UnionFind(n: Int) {
    private val parent = IntArray(n) { it }
    private val rank = IntArray(n)
    fun find(x: Int): Int {
        if (parent[x] != x) parent[x] = find(parent[x]) // 路径压缩
        return parent[x]
    }
    fun union(x: Int, y: Int): Boolean {
        val rx = find(x); val ry = find(y)
        if (rx == ry) return false
        if (rank[rx] < rank[ry]) parent[rx] = ry
        else if (rank[rx] > rank[ry]) parent[ry] = rx
        else { parent[ry] = rx; rank[rx]++ }
        return true
    }
}

fun kruskal(n: Int, edges: List<Triple<Int, Int, Int>>): Int {
    val sorted = edges.sortedBy { it.third } // 按边权升序
    val uf = UnionFind(n)
    var total = 0
    var count = 0
    for ((u, v, w) in sorted) {
        if (uf.union(u, v)) { // 不形成环才加入
            total += w
            count++
            if (count == n - 1) break
        }
    }
    return total
}
```
