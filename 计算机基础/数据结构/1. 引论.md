# 引论：数据结构基础与数学准备

## 一、本章内容

数据结构研究**如何高效地组织与存取数据**。当数据量较小时，存储方式对性能影响甚微；当数据量达到百万、千万级时，"如何组织"直接决定程序能否在可接受时间内完成。数据结构与**算法分析**互为表里：任何数据结构都要以某种方式实现，而实现方式直接决定操作的运行时间。本书讨论每一个数据结构时，均回答两个问题——**逻辑结构与存储结构**（其形态）以及**时间复杂度**（操作代价）。回答第二个问题需要两类工具：**数学工具**（对数、级数等，用于估算运行时间）与**递归思维**（用于描述与推导复杂结构）。本章即为此提供基础。

## 二、数学知识复习

> 本节为后续各章的复杂度讨论作铺垫。分析"循环嵌套""规模减半""递归展开"等代码的运行时间时，均会归结到以下公式。

### 1. 指数（Exponents）

指数表示连乘：$X^A$ 是 $X$ 自乘 $A$ 次。以下恒等式是推导复杂度的运算律：

- 同底相乘：$X^A X^B = X^{A+B}$
- 幂的幂：$(X^A)^B = X^{AB}$
- 同底相除：$\dfrac{X^A}{X^B} = X^{A-B}$
- 合并同类：$X^A + X^A = 2X^A$（注意不是 $X^{2A}$）

分析"循环每轮翻倍或减半"的代码时，运行时间常写成 $2^k$ 或 $N/2^k$ 的形式，化简即依赖上述规则。例如一个循环每轮将规模减半，共执行 $\log N$ 轮，总工作量 $N + N/2 + N/4 + \cdots \approx 2N$，其中同时用到了等比级数与指数。

### 2. 对数（Logarithms）

对数是指数的逆运算：$X^A = B$ 当且仅当 $\log_X B = A$（"以 $X$ 为底 $B$ 的对数是 $A$"，即"$X$ 自乘几次得到 $B$"）。由定义可推出：

- 乘积拆分：$\log AB = \log A + \log B$（乘变加）
- 商拆分：$\log(A/B) = \log A - \log B$（除变减）
- 幂下放：$\log A^B = B \log A$（指数变系数）
- 换底公式：$\log_A B = \dfrac{\log_C B}{\log_C A}$，对任意 $A,B,C>0$、$A\neq 1$ 成立。

换底公式表明所有对数底之间只差一个常数因子——例如 $\log_2 N = \dfrac{\log_{10} N}{\log_{10} 2}$，其中 $\dfrac{1}{\log_{10} 2}\approx 3.32$ 为常数。因此**在复杂度讨论中，对数的底不影响数量级**，$O(\log_2 N)$、$O(\log_{10} N)$、$O(\ln N)$ 本质等价。本书约定 $\log N$ 默认以 2 为底，$\ln N$ 为自然对数（以 $e$ 为底）。

另一常用结论：$\log X < X$ 对所有 $X>0$ 成立，即对数增长慢于任何线性函数，这是"对数级算法快于线性级算法"的数学依据。

### 3. 级数（Series）

分析循环累加时，级数给出求和的闭式结果：

- 几何级数：$\displaystyle\sum_{i=0}^{N} A^i = \dfrac{A^{N+1}-1}{A-1}$。当 $0 < A < 1$ 时，随 $N$ 增大收敛于 $\dfrac{1}{1-A}$。
  - 例：$\sum_{i=0}^{N} \frac{1}{2^i} < 2$，这是"规模每次减半的工作量总和不超过 $2N$"的来源。
- 算术级数：$\displaystyle\sum_{i=1}^{N} i = \dfrac{N(N+1)}{2} \approx \dfrac{N^2}{2}$。
  - 例：两层各循环 $N$ 次的嵌套循环，总次数为 $\sum_{i=1}^N \sum_{j=1}^N 1 = N^2$；插入排序"每次往前最多移动 $i$ 个位置"的代价即 $\sum i = O(N^2)$。
- 平方和：$\displaystyle\sum_{i=1}^{N} i^2 = \dfrac{N(N+1)(2N+1)}{6} \approx \dfrac{N^3}{3}$。
- 调和级数：$\displaystyle\sum_{i=1}^{N} \dfrac{1}{i} = H_N \approx \ln N + \gamma$（$\gamma \approx 0.577$，欧拉常数）。调和级数以对数速度增长，是散列装填因子分析（第 5 章）的数学基础。

### 4. 模运算（Modular Arithmetic）

若 $N$ 整除 $A-B$，则称 $A$ 与 $B$ **模 $N$ 同余**，记作 $A \equiv B \pmod N$，即"$A$ 与 $B$ 除以 $N$ 余数相同"。两条基本性质：

- 若 $A \equiv B \pmod N$，则 $A + C \equiv B + C \pmod N$；
- 若 $A \equiv B \pmod N$，则 $AD \equiv BD \pmod N$。

模运算是散列函数取模（第 5 章）、循环数组下标绕回（第 3 章队列）与随机化算法的代数基础。理解了"余数相同即同余"，即理解了散列表"多个键落到同一槽"的代数结构。

### 5. 证明的方法（简述）

- **归纳法**：先证基本情况成立，再证"若 $k$ 成立则 $k+1$ 成立"，常用于证明递归算法与循环不变量。
- **反证法**：假设结论不成立，推出与已知事实矛盾，从而结论必成立。
- **反例法**：反驳全称命题只需举出一个反例。

## 三、递归（Recursion）

递归是"一个函数直接或间接调用自身"的求解方式，是描述树（第 4 章）、分治、图遍历等结构的天然语言。

### 1. 递归的两条基本法则

1. **基准情形（base case）**：必须存在无需递归即可直接求解的情形，否则递归永不终止。
2. **不断推进（making progress）**：每次递归调用都必须朝基准情形靠近（如规模变小），且不能出现循环递归。

### 2. 示例一：打印正整数

设已有 `printDigit(n)` 可打印单个数字，打印任意正整数 `n` 的递归思路为：将"打印 $n$"拆为"打印高位 $n/10$"与"打印末位 $n\%10$"。

```
打印 762：
  先打印 76（= 762 / 10）
    先打印 7（= 76 / 10，7 < 10 触发基准情形，直接打印）
    再打印 6（= 76 % 10）
  再打印 2（= 762 % 10）
```

基准情形为 $n < 10$（只剩一位）直接打印。该示例表明：递归能将大问题拆分为结构相同的子问题，这是树与分治算法的核心思想。

### 3. 示例二：斐波那契数列（低效递归的典型）

斐波那契数列 $F_0=0,\ F_1=1,\ F_n = F_{n-1}+F_{n-2}$，具有两个基准情形（$n=0,1$），递归关系使 $n$ 逐步减小，语法上正确。但朴素递归实现会产生大量重复计算：

- 计算 $F_5$ 需算 $F_4$ 与 $F_3$；计算 $F_4$ 又需算 $F_3$ 与 $F_2$……$F_3$ 被重复计算两次、$F_2$ 三次。
- 重复计算量随 $n$ 指数爆炸，总复杂度约 $O(\varphi^n)$（$\varphi \approx 1.618$，黄金比例），$F_{40}$ 已需重复计算上亿次。

改进方法为记忆化（缓存已算结果）或自底向上迭代，可降至 $O(N)$。

> 判断递归是否高效，关键在于是否产生大量重复子问题。树结构（第 4 章）的递归遍历每个结点仅访问一次，是 $O(N)$ 的高效递归；朴素斐波那契则是低效递归的典型。

## 四、抽象数据类型（ADT）

### 1. 定义

**抽象数据类型（Abstract Data Type, ADT）** = 一个**数学模型** + 定义在该模型上的**一组操作**。其中：

- 数学模型描述对象本身（如"表"是 $A_0, A_1, \dots, A_{N-1}$ 的有序序列）；
- 一组操作描述可执行的动作及其语义（如表的 `insert(x)`、`findMin()`、`remove(idx)`）。

"抽象"强调 ADT 只规定**做什么**，不规定**怎么做**——它描述操作的语义契约（前置/后置条件），而非存储细节。

### 2. 示例：栈

以栈为例：模型为后进先出（LIFO）的元素序列；操作为 `push`（压入）、`pop`（弹出）、`top`（查看栈顶）；但不规定元素存于数组还是链表、栈顶位于哪一端。因此同一 ADT 可有多种实现，调用方仅依赖操作接口，不关心内部实现。ADT 的价值正在于将"接口"与"实现"解耦。

### 3. ADT 的意义

ADT 贯穿全书，是理解所有数据结构的组织范式：

1. **先抽象、后实现**：先确定"支持哪些操作及语义"，再考虑"用何种存储结构高效实现"，顺序不可颠倒。
2. **同一 ADT、多种实现**：不同实现有不同的时空权衡（如"表"有数组与链表两种实现，各有利弊），这是第 3 章的主题。
3. **面向接口思考**：在面向对象语言中，ADT 的操作集合通常对应接口（`interface`），实现对应具体类，"面向接口编程"即 ADT 思想的工程落地。

后续各章均按"**ADT 定义 → 具体实现 → 复杂度分析**"的范式展开。

## 五、小结

- 数据结构研究"如何组织数据使操作更快"，与算法分析互为表里。
- 指数、对数、级数、模运算是估算复杂度的基础；对数底不影响数量级。
- 递归是描述树与分治的天然语言，但需警惕重复子问题导致的指数级低效。
- ADT 是"模型 + 操作"的抽象，将接口与实现解耦，是全书数据结构的组织范式。
