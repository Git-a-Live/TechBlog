# 优先队列（堆）（Priority Queue / Heap）

## 一、优先队列的引入

普通队列按进入顺序出队（先进先出），但许多场景要求**按优先级出队**：操作系统调度中优先级高的进程先执行、急诊分诊中危重病人先看、事件模拟中先处理最早发生的事件、图算法（Dijkstra）中每次选距离最小的顶点。这些场景的共同需求是"每次取最重要的，而非最早来的"，即优先队列。

## 二、模型

优先队列 ADT 的核心操作：

| 操作 | 含义 |
| --- | --- |
| `insert(x)` | 插入元素 `x`（任意顺序） |
| `deleteMin()` | 找到并删除最小（或按需最大）的元素 |

此外常含 `findMin()`（查看最小而不删）、`isEmpty()`、`buildHeap()`（批量建堆）。

## 三、简单实现及其不足

| 实现 | insert | deleteMin | 说明 |
| --- | --- | --- | --- |
| 无序数组 | $O(1)$ | $O(N)$ | 插入快，找最小需遍历 |
| 有序数组 | $O(N)$ | $O(1)$ | 插入需移位保持有序 |
| 无序链表 | $O(1)$ | $O(N)$ | 同无序数组 |
| 有序链表 | $O(N)$ | $O(1)$ | 删除只需取队头 |

上述实现要么插入慢、要么删除慢，无法兼优。**二叉堆**将两者都做到 $O(\log N)$，批量建堆甚至 $O(N)$。

## 四、二叉堆（Binary Heap）

### 1. 两个性质

二叉堆是一棵有特殊序的完全二叉树，由两个性质定义：

1. **结构性质**：是**完全二叉树**，可用数组紧凑表示（下标从 1 开始，0 号位空置）：位置 $i$ 的左孩子 $2i$、右孩子 $2i+1$、父亲 $\lfloor i/2 \rfloor$。
2. **堆序性质（heap-order）**：以最小堆为例，**每个结点 ≤ 其所有孩子**（根即最小值）。它只要求"父 ≤ 子"，兄弟之间无大小关系。

```
        13            ← 根最小
       /  \
      21   16
     / \   / \
    24 31 19 68
```

数组表示：`[-, 13, 21, 16, 24, 31, 19, 68]`（0 号位不用）。

### 2. 插入（insert）：上滤（percolate up）

策略：将新元素放到数组末尾（最后一个叶子的下一空位），再不断与父结点比较、上浮，直到堆序恢复。

例：向上述最小堆插入 `14`。

```
① 放到末尾：                 [-, 13, 21, 16, 24, 31, 19, 68, 14]
                               14 的父亲是 68（位置 8 的父亲是 4）
② 14 < 68，上浮（与 68 交换）：[-, 13, 21, 16, 24, 31, 19, 14, 68]
                               14 的父亲变成 24（位置 4 的父亲是 2）
③ 14 < 24，继续上浮：         [-, 13, 21, 14, 24, 31, 19, 16, 68]
                               14 的父亲变成 21（位置 2 的父亲是 1）
④ 14 < 21，继续上浮：         [-, 13, 14, 21, 24, 31, 19, 16, 68]
                               14 的父亲变成 13（位置 1）
⑤ 14 > 13，停止。
```

新元素最多上浮到根，代价 $O(\log N)$（等于树高）。

```java
void insert(E x) {
    if (currentSize == array.length - 1) enlarge();
    int hole = ++currentSize;                // 空穴放在末尾
    for (; hole > 1 && x < array[hole / 2]; hole /= 2)
        array[hole] = array[hole / 2];       // 父结点下移，空穴上移
    array[hole] = x;                          // 放入最终位置
}
```

> 实现采用"父结点下移、空穴上移、最后一次性放入"，而非逐次交换，每次比较只搬一个元素。

### 3. 删除 deleteMin：下滤（percolate down）

策略：根是最小值，删除后留下空穴；将最后一个元素移到根空穴处，再不断与较小的孩子交换下沉。

例：删除最小堆的根 `13`（接上例）。

```
① 根 13 是最小值，删掉。
② 末元素 68 放到根空穴：      [-, 68, 14, 21, 24, 31, 19, 16]
③ 68 的孩子是 14、21，选较小者 14；68 > 14，下沉：
                                [-, 14, 68, 21, 24, 31, 19, 16]
④ 68 的孩子是 24、31，选较小者 24；68 > 24，继续下沉：
                                [-, 14, 24, 21, 68, 31, 19, 16]
⑤ 68 成为叶（位置 8），停止。
```

下沉时总选"较小的孩子"交换，保证交换后子树仍满足堆序，代价 $O(\log N)$。

### 4. 批量建堆 buildHeap：$O(N)$ 的关键

将 $N$ 个任意元素建成堆，朴素做法是逐个 insert，代价 $O(N \log N)$。更优做法为：把 $N$ 个元素随意放入数组（看作结构完整、堆序全无的完全二叉树），从 $\lfloor N/2 \rfloor$ 到 1 依次下滤（跳过叶结点，因为它们已是单结点堆）。

**复杂度为 $O(N)$ 而非 $O(N \log N)$ 的原因**：下滤代价与结点高度成正比，而大部分结点在下层、高度很小。第 $h$ 层的结点（约 $N/2^{h+1}$ 个）下滤代价 $h$，总代价 $\sum h \cdot \frac{N}{2^{h+1}} = O(N)$。此结论是堆排序的基础。

### 5. 复杂度总结

- `findMin`：$O(1)$（根即最小）。
- `insert`、`deleteMin`：$O(\log N)$。
- `buildHeap`：$O(N)$。

### 6. 应用

1. 选择问题：求第 $k$ 大/小元素，维护一个大小为 $k$ 的堆即可。
2. 事件模拟：按事件时间维护优先队列，模拟离散事件系统。
3. 图算法：Dijkstra、Prim 用堆维护"当前最近/最便宜"的候选。

## 五、d-堆（d-Heap）

二叉堆是 $d=2$ 的特例。$d$-堆每个结点有 $d$ 个孩子：树更扁，树高 $\log_d N$，`insert` 上滤路径更短（$O(\log_d N)$）；但 `deleteMin` 下滤需在 $d$ 个孩子中找最小，代价 $O(d \log_d N)$。适用于插入远多于删除的场景（如事件模拟大量入队、少量出队）。

## 六、左式堆（Leftist Heap）

二叉堆的合并需 $O(N)$（需将两个数组重新堆化），左式堆支持 $O(\log N)$ 的高效合并，为此引入新概念：

- **零路径长（null path length，NPL）**：结点 $X$ 到"没有两个孩子的结点"的最短路径长；`null` 的 NPL 定义为 $-1$。
- **左式性质**：对每个结点，左儿子的 NPL ≥ 右儿子的 NPL，即"零路径"偏向右侧、右路径短。

**合并**：递归地沿右路径合并两个堆（比较两个根，小者作根，递归合并其右子树与另一堆），并随时保证左式性质（若左 NPL < 右 NPL 则交换左右儿子）。右路径长 $O(\log N)$，故合并 $O(\log N)$。插入 = 单元素堆合并，删除 = 合并左右子树，均为 $O(\log N)$。

## 七、斜堆（Skew Heap）

斜堆是左式堆的自调整版本：合并过程与左式堆几乎相同，但无条件交换左右儿子（不维护 NPL，省去存储与判断开销）。摊还分析下合并为 $O(\log N)$，实现最简，实际性能通常很好。

## 八、二项队列（Binomial Queue）

二项队列是一组**二项树（binomial tree）**的集合，用于高效合并：

- 二项树 $B_k$：由两棵 $B_{k-1}$ 组成，根有 $k$ 个孩子，共 $2^k$ 个结点；$B_0$ 为单结点。
- 堆的大小 $N$ 的二进制表示对应"选哪些 $B_k$"（如 $N=13=8+4+1$，即 $B_3+B_2+B_0$）。
- 合并类似二进制加法，逐位合并同阶二项树，$O(\log N)$。
- deleteMin：先找最小根（$O(\log N)$），拆下它的孩子们（又是一组二项树），再与原队列合并。
- 插入 $O(1)$ 摊还（最坏 $O(\log N)$）。

## 九、标准库中的优先队列

`java.util.PriorityQueue<E>`：默认最小堆（按自然序或传入的 `Comparator`），`add`/`poll`（出队）/`peek` 均为 $O(\log N)$，底层是二叉堆的数组实现。

```java
PriorityQueue<Integer> pq  = new PriorityQueue<>();                      // 最小堆
PriorityQueue<Integer> max = new PriorityQueue<>(Comparator.reverseOrder()); // 最大堆
```

## 十、小结

| 结构 | insert | deleteMin | merge | 特点 |
| --- | --- | --- | --- | --- |
| 二叉堆 | $O(\log N)$ | $O(\log N)$ | $O(N)$ | 最常用，数组实现 |
| d-堆 | $O(\log_d N)$ | $O(d\log_d N)$ | — | 插入密集型场景 |
| 左式堆 | $O(\log N)$ | $O(\log N)$ | $O(\log N)$ | 可高效合并 |
| 斜堆 | $O(\log N)$ 摊还 | $O(\log N)$ 摊还 | $O(\log N)$ 摊还 | 实现最简单 |
| 二项队列 | $O(1)$ 摊还 | $O(\log N)$ | $O(\log N)$ | 二进制表示思想 |

核心结论：二叉堆是默认选择（$O(\log N)$ 插入删除、$O(N)$ 建堆、数组紧凑实现、缓存友好）；需要频繁合并两个优先队列时改用左式堆/斜堆/二项队列。理解二叉堆的上滤/下滤，即理解"堆序"这一贯穿堆排序、图算法与高级数据结构（配对堆等）的核心思想。
